## 第二批功能：提示词模板与技能管理

- 按 PM 指令完成提示词模板（Prompts）与技能（Skills）管理功能。
- 后端新增 `template-manager.ts`、`skill-manager.ts` 服务，数据持久化到 PI 原生数据目录（`PI_CODING_AGENT_DIR` 或 `~/.pi/agent`）下的 `prompts/` 与 `skills/` 文件夹，每个条目一个 JSON 文件。
- 后端新增 REST API：`/api/templates`、`/api/templates/categories`、`/api/skills`。
- 聊天路由集成技能触发：根据用户输入匹配启用的技能触发词（或 `alwaysOn`），自动将技能 Prompt 追加到系统消息。
- 前端新增独立页面 `/prompts` 与 `/skills`，支持 CRUD、分类筛选、搜索、启用/禁用。
- `MainLayout` 改为基于 `react-router-dom` `Outlet` 渲染子页面；`Sidebar` 底部新增提示词/技能页面导航入口。
- `ChatPage` 输入工具栏新增模板插入按钮；`PersonaTab` 支持将提示词模板内容应用到角色描述。
- 全部通过 `pnpm build` 与 `pnpm lint`。
