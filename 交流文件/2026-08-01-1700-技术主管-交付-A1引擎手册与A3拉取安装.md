## 三、A3 引擎拉取安装功能

### 3.1 核心功能

| 功能 | 说明 | 状态 |
|------|------|------|
| 本地源码安装 | 从 `D:\program\<engine>` 复制到 `ai-agent/<engine>/program/` | ✅ |
| 远程拉取 | 从 GitHub/镜像克隆源码 | ✅ |
| 镜像降级 | GitHub → gh-proxy.com → ghfast.top 自动降级 | ✅ |
| 进度上报 | 6 阶段进度（checking/cloning/installing/configuring/done/error） | ✅ |
| 幂等性 | 已安装时跳过，提示"已安装，无需重复安装" | ✅ |
| 重新安装 | `reinstall=true` 时清理旧版本后重装 | ✅ |
| 依赖安装 | 支持 pnpm/npm/bun/pip/go mod | ✅ |
| 配置写入 | 自动创建 data/sessions/prompts/skills/config 目录和 engine.json | ✅ |
| 错误处理 | 中文错误提示+建议操作 | ✅ |

### 3.2 引擎源配置

```typescript
ENGINE_SOURCES = {
  pi:        { localSource: 'D:\\program\\pi-agent',        dependencies: 'pnpm' },
  hermes:    { localSource: 'D:\\program\\hermes-agent',    dependencies: 'pip/uv' },
  claude-code:{ localSource: 'D:\\program\\claude-code',    dependencies: 'npm' },
  codex:     { localSource: 'D:\\program\\codex',           dependencies: 'cargo/pnpm' },
  opencode:  { localSource: 'D:\\program\\opencode',         dependencies: 'bun/pnpm' },
  reasonix:  { localSource: 'D:\\program\\reasonix',        dependencies: 'go/npm' },
}
```

### 3.3 API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/engines/sources` | 获取所有引擎源信息 |
| GET | `/api/engines/list` | 获取引擎安装列表 |
| GET | `/api/engines/:id/source` | 获取单个引擎源信息 |
| POST | `/api/engines/:id/install` | 安装引擎 |
| GET | `/api/engines/status` | 获取所有引擎状态 |
| GET | `/api/engines/status/:id` | 获取单个引擎状态 |
| POST | `/api/engines/:id/init` | 初始化引擎目录 |
| GET | `/api/engines/:id/paths` | 获取引擎路径 |
| GET | `/api/engines/location` | 位置检查 |
| GET | `/api/engines/ai-agent-root` | 获取 ai-agent 根目录 |

### 3.4 安装流程

```
POST /api/engines/:id/install
Body: {
  useLocalSource: true,  // 默认优先本地
  reinstall: false       // 是否强制重新安装
}
```

**本地安装流程**：
```
① 检查引擎状态 → ② 复制本地源码 → ③ 安装依赖 → ④ 配置数据目录 → ⑤ 完成
```

**远程安装流程**：
```
① GitHub 直连（15s 超时）
② 失败 → gh-proxy.com（15s 超时）
③ 失败 → ghfast.top（15s 超时）
④ 全部失败 → 返回中文错误+建议
```
