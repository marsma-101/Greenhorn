## 一、问题描述

**现象**：claude-code 已安装（`ai-agent/claude-code/program/` 有内容、engine.json 正确），但 `GET /api/engines/status` 显示 `installed: false`。

**根因**：状态检测 marker 文件配置为 `['package.json', 'settings.json']`，但 claude-code 仓库根目录没有 package.json 文件。

---

## 二、修复内容

### 修改文件
- `packages/backend/src/services/ai-agent-manager.ts`

### 修改内容
```typescript
// 修复前
markerFiles: ['package.json', 'settings.json'],

// 修复后
markerFiles: ['README.md', 'LICENSE.md', 'Script'],
```

claude-code 仓库根目录实际存在的文件：
- `README.md` ✅
- `LICENSE.md` ✅
- `Script/` 目录 ✅
