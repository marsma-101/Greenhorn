## 一、现象描述

用户启动 GreenHorn（通过桌面 HTML launcher）后，浏览器弹出页面显示：

```
加载配置失败

API /settings: 404

[ 重试 ]
```

## 二、初步定位

### 检查结果

| 检查项 | 结果 |
|--------|------|
| 前端代码搜索 `/api/settings` | ❌ 没找到 |
| 前端代码搜索"加载配置失败" | ❌ 没找到 |
| 后端路由检查 `/settings` | ❌ 没找到（只有 `/api/config`） |
| 后端路由检查 `/api/settings` | ❌ 没找到 |
| Launcher HTML 含"加载配置失败"文案 | ❌ 没找到 |

### 推测

1. 浏览器实际访问的 URL 是 `/settings` 或 `/api/settings`，但后端没有这个端点
2. 报错页面可能来自：
   - 浏览器自身的 404 页面（被前端 catch 后捕获）
   - 某段代码 try-catch 后显示的友好提示
   - 或是 user 的浏览器/Vite 拓展加的覆盖页面

### 复现路径

```
打开 GreenHorn launcher (http://localhost:3001)
    ↓ 点击启动
后端启动 (http://localhost:3000)
    ↓ 自动跳转
打开前端 (http://localhost:5173)
    ↓ 用户点击某个入口
进入设置页面
    ↓ 出现错误
```
