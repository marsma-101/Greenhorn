### 需要确认的 2 个问题

**Q1：安装过程中的拉取动作，走什么镜像源？**

> 国内用户从 GitHub 拉 PI 源码可能很慢甚至失败，需要配置镜像源。

方案：
- 默认拉取路径：`https://github.com/earendil-works/pi.git`
- 失败时额外提供 Gitee 镜像：`https://gitee.com/mirrors/pi.git`（如果存在）
- 或允许用户粘贴自定义镜像地址

**Q2：环境检测的"通过"标准是什么？**

| 检测项 | 通过标准 | 不通过提示 |
|--------|---------|-----------|
| Node.js | 需 >= 18.x | "请先安装 Node.js（当前版本：xx）" |
| Git | 已安装 | "需要 Git 来拉取代码" |
| pnpm | 已安装 | "需要 pnpm 来安装依赖" |
| 磁盘空间 | C 盘 > 5GB 可用 | "C 盘空间不足，建议选其他盘" |

以上标准是否 OK？
