## 问题

设置页「智能体身份」文本框的内容没有在对话中生效。虽然在 `~/.pi/agent/settings.json` 中正确保存了 `persona` 字段，但实际发送消息时 AI 没有遵循 persona 的指令。

## 排查记录

1. `settings.json` 中 `persona` 已正确保存 ✅
2. `GET /api/settings` 返回的 `persona` 字段正确 ✅
3. 前端 ChatPage 第 165 行将 `selectedPersona` 作为 `persona` 参数发送给后端 ✅
4. 后端 `chat.ts` 中 `readPersona()` 读取到的值也正确 ✅
5. `chat.ts` 将 `persona` 和 `systemMessage` 都传入 `streamChat()` ✅
6. `chat-engine.ts` 中也有 `persona` 注入 system prompt 的逻辑 ✅

## 可能原因

代码层面看起来都正确，怀疑是运行时问题：
- **双注入问题**：`chat.ts` 将 persona 注入 `systemMessage`，`chat-engine.ts` 又注入一次，可能导致格式异常
- 或：后端需要重新编译后未重启
- 或：某些情况下 `persona` 被空字符串覆盖

1. 本地运行，在设置页填入 persona 并保存
2. 发送一条测试消息（如"我叫什么？"）
3. 检查后端日志中实际发送给 API 的 system prompt 是否包含 persona 内容
4. 修好后通知 PM 验收
