## 修复内容

### P0-1：PI 卡片一直显示"检测中..."

| 文件 | 改动 |
|------|------|
| [HomePage.tsx](file:///d:/program/GreenHorn/packages/frontend/src/pages/HomePage.tsx#L26) | `fetch('/api/pi/check')` → `fetch('/api/pi/')` |

**根因**：前端调用 `/api/pi/check`，但后端只注册了 `/api/pi/` 路由。请求不匹配任何 API 路由，落到 SPA fallback 返回 HTML，前端解析失败，`piStatus` 永远停在 `'checking'`。

**验证结果**：✅ 已修复
- API `/api/pi/` 返回 `{"installed":true,...}`
- PI 卡片从黄色"检测中..."变为绿色**"已就绪"**

### P1：点击 PI 和 Ollama 结果一样

| 文件 | 改动 |
|------|------|
| [ChatPage.tsx](file:///d:/program/GreenHorn/packages/frontend/src/pages/ChatPage.tsx#L4-L26) | 新增 `PI_SAMPLE_QUESTIONS`、`OLLAMA_SAMPLE_QUESTIONS`、`EMPTY_STATE` 映射；空状态根据 `provider` 显示不同内容 |
