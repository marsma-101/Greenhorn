## 三、任务 2：对话页智能体标识

### 交付物

|------|----------|
| `packages/frontend/src/pages/ChatPage.tsx` | 新增智能体标识头部组件 |

### 功能清单

| 功能 | 实现 |
|------|------|
| 读取 engine 参数 | `useSearchParams().get('engine')` |
| 默认引擎 | 无参数时默认显示 PI |
| 标识显示 | 图标 + 名称 + 一句话描述 |
| 切换按钮 | 「切换 ▾」占位，点击提示"多智能体切换开发中" |
| 主题自适应 | 使用 CSS 变量，适配三主题 |

### 技术实现

```tsx
// URL 参数读取
const [searchParams] = useSearchParams();
const engineId = searchParams.get('engine') || 'pi';
const currentEngine = ENGINES.find(e => e.id === engineId) || ENGINES[0];

// 智能体标识头部
<div className="flex items-center gap-2">
  <span>{currentEngine.emoji}</span>  {/* 引擎图标 */}
  <div>
    <div>{currentEngine.name}</div>  {/* 引擎名称 */}
    <div>{currentEngine.description}</div>  {/* 一句话描述 */}
  </div>
  <button>切换 ▾</button>  {/* 占位按钮 */}
</div>
```

## 五、使用说明

### 访问不同引擎的对话页

```
默认 PI：/chat
Hermes：/chat?engine=hermes
Claude Code：/chat?engine=claude-code
Codex：/chat?engine=codex
OpenCode：/chat?engine=opencode
Reasonix：/chat?engine=reasonix
```

### 网页安装器使用

1. 打开 `安装 GreenHorn.html`
2. 选择安装方式：
   - **下载 ZIP**：点击下载按钮，解压后双击 `start.bat`
   - **安装脚本**：下载 `install.bat`，双击自动安装
   - **克隆命令**：复制 git clone 命令到终端执行
