## 一、问题

目前 GreenHorn 有 3 个缺失的关键功能：

1. **对话历史不保存** — 刷新页面 → 回到初始状态，历史对话全部丢失。无法查看历史、无法切换回之前的对话。
2. **无文件选择** — 用户不能选择文件给 AI 看，AI 无法感知项目上下文。
3. **无智能体设定** — 用户不能设置 AI 的行为角色（如"我是一个 Python 工程师""用中文回答"等）。

这些 PI 本身都有原生支持，GreenHorn 只是缺少对应的 UI 入口。

## 二、功能需求

### P1：对话历史管理

**目标**：用户能看到历史会话列表，切换回之前的对话，开始新对话。

**交互方式**：

```
对话页面顶部或左侧：
┌─────────────────────────┐
│ 🍃 GreenHorn            │
│ ┌─────────────────────┐ │
│ │ 历史对话 ▼           │ │
│ │ ├ 帮我写一个API (5分钟前)│ │
│ │ ├ React 问题 (1小时前) │ │
│ │ ├ 项目架构讨论 (昨天)  │ │
│ │ └ + 新建对话         │ │
│ └─────────────────────┘ │
│                          │
│ 消息区域...               │
└─────────────────────────┘
```

**技术方案**：

PI 的原生会话存储在 `~/.pi/agent/sessions/` 目录，JSONL 格式。GreenHorn 可以：
1. 后端新增 `GET /api/sessions` — 列出所有历史会话（标题、时间、摘要）
2. 后端新增 `GET /api/sessions/:id` — 加载指定会话的历史消息
3. 后端新增 `POST /api/sessions` — 创建新会话
4. 前端对话页面加载时调 `GET /api/sessions` → 显示列表
5. 前端切换会话时 / 刷新时 → 通过 sessionId 恢复消息

**详细参考**：PI 文档 `docs/session-format.md` 和 `docs/sessions.md` 说明了会话文件的格式和存储规则。

### P2：文件选择

**目标**：用户能选择要发给 AI 的文件。

**交互方式**：

```
输入框上方或旁边：
┌─────────────────────────────┐
│ 📎 选择文件 已选: 2 个文件    │
│   ├ src/index.ts             │
│   └ package.json             │
│                              │
│ [输入你的问题...        ] [发送]│
└─────────────────────────────┘
```

**技术方案**：
- 文件选择器（浏览器原生 `<input type="file">` 或目录选择）
- 选中的文件内容在发送请求时作为上下文发送给后端
- 后端将文件内容注入到对话的 system prompt 中

### P2：智能体设定

**目标**：用户能自定义 AI 的行为角色。

**交互方式**：
- 设置页新增"智能体设定"区域
- 一个文本框输入自定义指令（如"你是一个 Python 专家"）
- 预设几个角色模板（通用助手、代码专家、翻译助手等）

**技术方案**：
- 前端保存自定义指令到 `settings.json` 或新建配置项
- 每次对话时，后端将自定义指令注入到 system prompt 中

### P3：功能说明

**目标**：每个新功能旁边都有 (?) 说明按钮，解释"这是什么"、"怎么用"。

| 功能 | 说明文案 |
|------|---------|
| 对话历史 | 保存你的所有对话，可以随时切换回之前的对话继续聊 |
| 文件选择 | 选择项目文件发给 AI，AI 能理解你的代码上下文 |
| 智能体设定 | 告诉 AI 你应该扮演什么角色，比如"你是一个 Python 专家" |
