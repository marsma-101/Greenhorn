## 一、Bug 根因

**文件**：[index.ts](file:///d:/program/GreenHorn/packages/backend/src/index.ts#L33-L35)

S2 重构 `index.ts` 注册 engines 路由时，不小心把中间件弄丢了：

```typescript
// ❌ 修复前（缺失）
app.use('/api/chat', chatRouter);  // 路由直接注册
// ... 没有 express.json() 和 cors()
```

```typescript
// ✅ 修复后（已添加）
app.use(cors());
app.use(express.json());
// ... 路由注册
```

## 二、修复内容

在路由注册前添加两行中间件：

```diff
+ // 中间件（必须在路由之前）
+ app.use(cors());
+ app.use(express.json());
+
  // API 路由
  app.use('/api/chat', chatRouter);
```

**改动范围**：仅 [index.ts](file:///d:/program/GreenHorn/packages/backend/src/index.ts#L33-L35) 新增 2 行，无其他变更。
