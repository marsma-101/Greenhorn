# PM 指令 · 删除首页 Ollama 入口

> 发出人：小菠萝 🍍（PM）
> 接收人：技术主管（Trae）
> 日期：2026-08-01
> 状态：待执行
> 优先级：P1

---

## 需求

**首页/引擎选择流程彻底移除 Ollama 入口，任何用户（新手/老手）都不显示。**

## 原因

1. Ollama 需要用户单独安装，小白没装 → 按钮点了没用 → 混乱
2. 首页入口应该聚焦"智能体引擎 + 云端 API"，不展示需要额外环境的东西
3. 目标用户是小白，首页越简单越好

## 具体改动

### 1. 首页引擎选择卡片（删除）

- 删除「🦙 Ollama」选择卡片（HomePage / 引擎选择界面）

### 2. 引擎选择流程（删除）

- 选择智能体引擎的列表里不再出现 Ollama

### 3. ✅ 必须保留的（防误删清单）

**以下 Ollama 相关内容全部保留，不要动：**

| 保留项 | 位置 | 说明 |
|--------|------|------|
| Ollama provider 选项 | ⚙️ 模型设置页 → 模型来源下拉 | 对话时选 Ollama 作为 API 提供商 |
| Ollama 模型列表 | 模型设置页 | qwen3.5:9b、qwen3.5:32b、llama3.1 等已注册模型 |
| Ollama 连接配置 | 设置页 API Key 区域 | 显示"Ollama 无需 API Key"及 baseUrl 配置 |
| Ollama 对话链路 | 后端 chat-engine | ollama provider 的请求处理逻辑 |
| Ollama 验证 | /api/ollama 相关接口 | 连接验证功能 |

**总结：删的只有"首页和引擎选择流程里的 Ollama 入口卡片"，Ollama 作为"模型/API 提供商"的功能全部保留。**

### 4. 其他入口检查

- 全前端搜索 Ollama 相关入口（按钮/卡片/导航）：
  - ❌ 删除：首页卡片、引擎选择列表项
  - ✅ 保留：模型设置下拉、对话页模型选择下拉（若存在）、设置页所有 Ollama 配置
