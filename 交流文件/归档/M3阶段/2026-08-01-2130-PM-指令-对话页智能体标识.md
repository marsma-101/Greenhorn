## 一、需求背景

用户进入不同智能体项目对话时，界面**没有当前智能体的标识**，不知道正在和哪个智能体对话。

**需求**：
1. 对话页**左上角**显示当前正在使用的智能体标识/标签
2. 为将来**多智能体同时运行**预留查看入口

---

## 二、功能设计

### 2.1 对话页左上角智能体标识

在 ChatPage 顶部（消息区上方）新增智能体标识：

```
┌────────────────────────────────────────────────┐
│ 🍍 PI · 轻量级编程助手          [对话中]  [切换▾] │  ← 左上角标识
├────────────────────────────────────────────────┤
│  消息区...                                      │
```

### 2.2 标识内容

| 元素 | 说明 |
|------|------|
| 引擎图标 | 对应引擎的图标（沿用主题系统 SVG/Emoji） |
| 引擎名称 | PI / Hermes / Claude Code / Codex / OpenCode / Reasonix |
| 一句话描述 | 从 ENGINES 数组取 description |
| 状态标签 | 当前对话引擎（后续多智能体运行时可显示"运行中"） |
| 切换入口 | 「切换 ▾」下拉（预留，当前版本可只显示不跳转或提示开发中） |

### 2.3 数据来源

ChatPage 需要知道当前是哪个引擎——从 URL 参数读取：
- 当前跳转逻辑：`/chat?engine=xxx`（HomePage 已实现）
- **ChatPage 目前没有读取 `engine` 参数**，需要新增：
  - 从 `window.location.search` 或 useSearchParams 读 `engine`
  - 根据 engine id 从 ENGINES 常量找到名称/描述/图标
  - 默认（无参数或 engine=pi）显示 PI

### 2.4 多智能体运行入口（预留）

- 左上角标识区做成本区域可扩展：
  - 当前版本：显示当前引擎标识 + 「切换 ▾」占位（点击提示"多智能体切换开发中"）
  - 后续版本：多个运行中的智能体标签平铺，可点击切换

---

## 三、交互细节

1. 标识常驻（滚动消息时也可见，固定在顶部）
2. 样式与当前主题一致（使用 CSS 变量，深色/浅色自适应）
3. 「切换 ▾」下拉：当前版本提示"多智能体切换功能开发中，敬请期待"
4. 与「💬 智能体对话」等其他顶部元素不冲突

---

## 四、验收标准

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 标识显示 | 对话页左上角显示当前引擎图标 + 名称 + 描述 |
| 2 | 引擎正确 | 从 `/chat?engine=hermes` 进入显示 Hermes，`engine=pi` 显示 PI |
| 3 | 默认值 | 无参数时显示 PI（默认引擎） |
| 4 | 常驻显示 | 滚动消息时标识固定在顶部 |
| 5 | 主题适配 | 深色/浅色主题下样式正常 |
| 6 | 切换占位 | 「切换 ▾」点击有提示（开发中） |
| 7 | 编译通过 | pnpm build 无错误 |
