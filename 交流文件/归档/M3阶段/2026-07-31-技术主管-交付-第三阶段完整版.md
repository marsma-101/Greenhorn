## 二、Bug 修复

### Bug 1：start.bat 浏览器恢复旧标签页
- **修复**：启动 URL 加随机参数 `?fresh=%TIME%`，强制浏览器打开新标签
- **文件**：[start.bat#L75-78](file:///d:/program/GreenHorn/scripts/start.bat#L75-L78)

### Bug 2：对话失败（Ollama 模型名带前缀）
- **原因**：config API 返回 `ollama/qwen3.5:9b`（PI 格式），Ollama 只认 `qwen3.5:9b`
- **修复**：config API 自动剥离 `provider/` 前缀
- **文件**：[config.ts#L85-87](file:///d:/program/GreenHorn/packages/backend/src/routes/config.ts#L85-L87)

### Bug 3：Ollama URL 缺少 /v1
- **原因**：ChatPage 硬编码 `http://localhost:11434`，但正确地址是 `http://localhost:11434/v1`
- **修复**：改用 `config.baseUrl`（从 auth.json 读取）
- **文件**：[ChatPage.tsx#L142](file:///d:/program/GreenHorn/packages/frontend/src/pages/ChatPage.tsx#L142)

### Bug 4：侧边栏标签状态不同步
- **原因**：4 个标签组件用 `useState(() => {...})` 同步 settings，但该写法只在首次渲染执行（此时 settings 未加载）
- **修复**：全部改为 `useEffect`，settings 加载后正确同步
- **文件**：AppearanceTab / ModelTab / PersonaTab / AdvancedTab

## 四、多主题系统（新增）

### 设计思路

使用 **CSS 变量驱动** + `data-ui-style` 属性切换，React 层只负责切换属性值和图标类型，不重渲染样式。

### 主题一：默认主题（GreenHorn 绿色系）

| Token | 值 |
|-------|-----|
| 主色 `--c-accent` | `oklch(62% 0.15 145)` 竹叶绿 |
| 背景 `--c-bg-page` | `oklch(99% 0.005 145)` 浅米白 |
| 面板 `--c-surface-1` | 白色 + 毛玻璃 |
| 圆角 | `--r-xs=4px / r-sm=8px / r-md=12px / r-lg=16px` |
| 图标 | Emoji（📄 ⚙️ 🤖 🎨 📁 ⚡） |
| 字体 | `-apple-system, PingFang SC, Microsoft YaHei, sans-serif` |

### 主题二：Claude 风格（暖米色 + 陶土橙）

| Token | 值 |
|-------|-----|
| 主色 `--c-accent` | `#C9562C` 陶土橙 |
| 背景 `--c-bg-page` | `#F5F0E8` 暖米色 |
| 面板 `--c-surface-1` | `#FFFFFF` 纯白（纸张感） |
| 圆角 | `--r-xs=2px / r-sm=4px / r-md=6px / r-lg=8px` |
| 图标 | SVG stroke 风格（1.5px 线宽，圆角端点） |
| 字体 | 衬线 Georgia/Cambria（标题）+ 系统无衬线（正文） |

### 主题切换实现

```
用户在外观标签 → 选「Claude 风格」→ setUIStyle('claude')
  └─> document.documentElement.dataset.uiStyle = 'claude'
        └─> [data-ui-style="claude"] CSS 规则覆盖变量
              └─> useSVG = true → 所有图标条件渲染切换为 SVG
```

**实时预览**：`AppearanceTab` 中选择后立即通过 `useEffect` 预览，点击"保存"后持久化到 `settings.json`。

## 五、视觉设计应用（原第四节递增）

### impeccable skill 设计原则

| 原则 | 应用 |
|------|------|
| OKLCH 色彩 | 全局使用 `oklch()` + 绿色色调（hue 145） |
| 4pt 间距 | 所有间距使用 4/8/12/16/24/32px |
| 动效 | 侧边栏 300ms `cubic-bezier(0.16, 1, 0.3, 1)`，hover 200ms |
| 仅动画 transform/opacity | toggle 位移用 transform，不用 width/left |
| 减少动画偏好 | `@media (prefers-reduced-motion: reduce)` |

### PM 参考产品应用

| 参考 | 应用 |
|------|------|
| 豆包圆润风格 | 大圆角（12-16px）、柔和配色、毛玻璃侧边栏 |
| Claude 纸张式 | 对话区 paper-card 白色圆角卡片 + 轻阴影 |
| ChatGPT 工具栏 | 📎文件 + 模型下拉 + 身份下拉 + ⚡加速 一行排列 |

### 具体视觉要求对照

| PM 要求 | 实现 |
|---------|------|
| 主色绿色系 | OKLCH hue 145，chroma 0.12-0.15 |
| 圆角 12-16px | 卡片 `rounded-2xl`(16px)，按钮 `rounded-xl`(12px) |
| 系统字体 | `-apple-system, PingFang SC, Microsoft YaHei` |
| 4px 间距基准 | 全局使用 |
| 焦点发光边框 | `.input-glow:focus` 绿色光晕 |
| 轻阴影层次 | `--shadow-sm/md/lg` 三级阴影 |
| 侧边栏 0.3s ease | `sidebar-transition` class |
| 自定义滚动条 | 6px 宽，圆角，绿色调 |
