## 一、🔴 P0 严重 bug：所有 POST 接口崩溃

### 现象

实测发现**所有 POST 请求都失败**，包括对话功能：

| 接口 | 实测结果 |
|------|---------|
| `POST /api/chat` | ❌ 后端崩溃（对话功能坏了！） |
| `POST /api/templates` | ❌ 创建模板失败 |
| `POST /api/skills/check-safety` | ❌ 安全检测失败 |
| `POST /api/skills/scan` | ❌ 扫描文件夹失败 |
| `POST /api/skills/import` | ❌（同类问题） |

### 根因

**`packages/backend/src/index.ts` 缺少 `app.use(express.json())` 中间件！**

当前 index.ts 只有：
```typescript
app.use(express.static(frontendDist));  // 只有这个
```

**没有：**
```typescript
app.use(express.json());  // ← 缺失！
```

导致所有 POST 请求的 `req.body` 都是 `undefined`，后端日志：
```
Error checking safety: TypeError: Cannot read properties of undefined (reading 'prompt')
Error creating template: TypeError: Cannot read properties of undefined (reading 'name')
```

### 影响

**对话功能完全不可用**（chat 路由 `req.body` 解构直接崩）——这是阻断级问题。

### 修复

在 `index.ts` 路由注册前加一行：
```typescript
app.use(express.json());
```

> 疑似 S2 重构 index.ts（注册 engines 路由）时把中间件弄丢了。git 历史确认早期版本 `bd9e478` 有 `express.json()`。
