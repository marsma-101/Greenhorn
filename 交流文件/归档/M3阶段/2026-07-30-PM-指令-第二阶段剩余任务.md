## 二、本次任务（以下全部实现）

### P2-1：文件选择器

对话页输入框上方加文件选择按钮。

```
输入框区域：
┌─────────────────────────────────────────┐
│ 📎 选择文件        已选: 2 个文件         │
│   ├ src/index.ts                        │
│   └ package.json                        │
│                                         │
│ [输入你的问题...                  ] [发送] │
└─────────────────────────────────────────┘
```

**技术**：
- 使用浏览器原生 `<input type="file" multiple>`
- 限制 500KB，文本文件（.txt .md .json .js .ts .py .html .css .xml .yaml .csv）
- 发送时文件内容作为 `system` 消息注入：`"用户上传了文件 {filename}，内容如下：\n---\n{content}\n---"`
- 超过 20000 字符自动截断

### P2-2：智能体设定（Persona）

设置页「高级设置」区域（或设置页底部）新增：

```
🤖 智能体设定

角色描述：
[你是一个 Python 专家，擅长后端开发和 API 设计]

预设模板： [通用助手] [代码专家] [翻译助手] [教师模式]

(?) 告诉 AI 应该扮演什么角色，影响所有回答的风格
```

**技术**：
- 后端 `PUT /api/config` 保存 `persona` 字段到 `settings.json`
- 每次对话时，后端在 system prompt 前部注入
- 预设模板存在前端常量数组
