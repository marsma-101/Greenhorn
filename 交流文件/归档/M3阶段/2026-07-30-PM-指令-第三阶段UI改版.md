## 二、第三阶段启动：UI 全面改版

### 核心概念

```
┌─────────────────────────────────────────────────────┐
│  整个界面 = 一张桌面                                   │
│                                                      │
│  ┌──────┬──────────────────────────────────────────┐ │
│  │ 标签  │  对话区域（一张纸）                        │ │
│  │ 侧边栏│                                          │ │
│  │      │  用户在上面写字                            │ │
│  │ 📄   │  AI 回复也写在同一张纸上                   │ │
│  │ ⚙️   │                                          │ │
│  │ 🤖   │                                          │ │
│  │ 🎨   │                                          │ │
│  │ 📁   │  输入框: [                    ] [发送]     │ │
│  │ ⚡   │                                          │ │
│  │      │                                          │ │
│  │ [📌] │                                          │ │
│  └──────┴──────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 详细设计

#### 1. 标签侧边栏（左侧）

- **默认状态**：收起（隐藏），只显示一条细的标签列
- **展开方式**：点击标签 → 侧边栏滑出（动画 0.3s）
- **固定功能**：侧边栏右上角有 📌 固定按钮，点击后侧边栏保持展开
- **标签切换**：固定状态下，点击不同标签切换内容，侧边栏不收起
- **关闭方式**：已固定时点 📌 取消固定，未固定时点标签外区域收起

#### 2. 标签清单

| 图标 | 标签名 | 内容 |
|------|--------|------|
| 📄 | 对话管理 | 会话列表、切换、改名、删除、新建对话 |
| ⚙️ | 模型设置 | 当前设置页内容（供应商、Key、模型选择） |
| 🤖 | 智能体 | 角色设定、预设模板（当前设置页的智能体设定） |
| 🎨 | 外观 | 主题切换（浅色/深色/跟随系统）、思考过程开关 |
| 📁 | 工作台 | PI 工作目录文件浏览和管理 |
| ⚡ | 高级 | 当前高级设置页内容（thinkingLevel、compaction 等） |

#### 3. 对话区域

- 视觉风格：一张白色/淡色"纸"，圆角，带一点阴影
- 用户消息：写在纸上的文字
- AI 回复：写在纸上的回复
- 输入框：纸张底部的输入区域

#### 4. 对话页新增控件

输入框上方增加一行工具栏：

```
[📎 文件]  [模型: DeepSeek V3 ▾]  [身份: 代码专家 ▾]  [⚡ 加速]
```

- 模型下拉：显示所有已注册并验证通过的模型
- 身份下拉：显示 settings.json 中已配置的不同 persona
