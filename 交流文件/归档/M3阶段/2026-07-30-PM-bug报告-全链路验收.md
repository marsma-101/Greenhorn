## 🔴 P0（阻断性）

### P0-1：PI 卡片一直显示"检测中..." 
**路径**：首页 `/`
**复现**：打开首页 → PI 卡片显示"检测中..." → 刷新页面 → 依然"检测中..."
**处理**：**不改，改用新设计。** 首页去掉预检测，改为点击 PI 卡片时按需检测。见 `2026-07-30-PM-需求-PI检测改版.md`

### P0-2：点击样本问题 → AI 回复报 404
**路径**：聊天页 `/chat?provider=ollama`
**复现**：打开聊天页（Ollama 模式）→ 输入消息或点击样本问题 → 显示 `❌ 请求失败: 404 page not found`
**根因**：`chat-engine.ts:36` URL 模板是 `${baseUrl}/chat/completions`。Ollama 的 `baseUrl` 是 `http://localhost:11434`，拼成 `http://localhost:11434/chat/completions`，但 Ollama 的 OpenAI 兼容 API 实际路径是 `http://localhost:11434/v1/chat/completions`。
**修复**：二选一
- 方案 A：`chat-engine.ts` 加 `/v1/` → `${baseUrl}/v1/chat/completions`
- 方案 B：`PROVIDER_URLS` 中 Ollama 的 URL 改为 `http://localhost:11434/v1`

---

## 🟡 P1（重要）

### P1-1：AI 对话 404 影响所有模型供应商
同 P0-2 根因。不只是 Ollama，**所有供应商的 API URL 都拼错了路径**——`${baseUrl}/chat/completions` 而非 `${baseUrl}/v1/chat/completions`。DeepSeek 等云端 API 也要求 `/v1/` 路径。**聊天功能实际上全线不可用。**
