## 一、提示词模板管理

### 功能位置
侧边栏「🤖 智能体」tab → 子区「提示词模板」

### 功能列表

| 功能 | 说明 |
|------|------|
| 模板列表 | 卡片式展示 `~/.pi/agent/prompts/*.md`：文件名 + 描述 + 修改时间 |
| 新建模板 | 点击「+ 新建模板」→ 自动生成一个**空模板 md 文件**供用户参照填写 |
| 编辑模板 | 点击模板 → 直接编辑 md 内容 |
| 删除模板 | 删除对应 md 文件 |

### 新建模板的参照格式（空模板内容）

新建时生成如下模板文件，用户照着填写：

```markdown
---
description: 一句话描述这个模板的用途（显示在 /模板名 的提示里）
argument-hint: "[可选参数提示，如 <文件路径>]"
---

在这里写下模板内容。可以包含参数占位符：
- $1 表示第一个参数
- $2 表示第二个参数
- $@ 表示全部参数

示例：/review 会展开成完整提示词发送给 AI
```

### 使用说明
- 模板文件名 = 命令名（`review.md` → `/review`）
- 对话页输入框敲 `/模板名` 展开成完整提示词
- 模板内容支持 `$1` `$2` `$@` 参数占位符

## 二、技能管理

### 功能位置
侧边栏「🤖 智能体」tab → 子区「技能库」

### 功能列表

| 功能 | 说明 |
|------|------|
| 技能列表 | 卡片式展示所有已发现技能：技能名 + 描述 + 来源标签 + 安全提示 |
| 技能库扩充（4 入口） | 见下方详述 |
| 调用模式切换 | 「自动 / 手动」二选一 |
| 对话页手动调用按钮 | 见下方详述 |

### 2.1 技能库 4 个扩充入口

| 入口 | 说明 |
|------|------|
| **AI 自动生成** | 用户描述需求（如"我要一个写周报的技能"），AI 生成 SKILL.md 存入技能库 |
| **线上安装** | 从技能市场/仓库拉取安装 |
| **本地安装** | 用户选择本地文件夹，作为技能装入技能库 |
| **扫描外部文件夹** | 用户指定目录（如 `~/.claude/skills`），扫描其中技能加入技能库 |

### 2.2 调用模式：自动 / 手动（不是开/关）

设置项：**技能调用模式**，两个选项：

| 选项 | 说明（界面展示文案） |
|------|---------------------|
| **自动** | AI 会根据你的需求自动判断并调用合适的技能。优点：省心，AI 自主决定何时用技能。缺点：可能出现调用不合适的技能（调用错误），且技能加载会消耗更多 token |
| **手动** | 只有你明确选择技能时才调用。优点：精准，只调用你指定的技能。缺点：操作较繁琐；如果你忘记手动指定技能，AI 只能靠自身基础能力完成任务，可能增加工作量，同时也会增加 token 消耗 |

### 2.3 对话页手动调用技能按钮

对话页输入框下方工具栏新增「🧰 技能」按钮：
- 点击弹出技能列表，勾选技能加入本次对话
- **不受调用模式影响**——无论自动还是手动模式，都可以通过这里手动指定技能

### 2.4 安全提示（保留，但只做提示不做强制审查）

技能卡片上，**包含可执行代码或可自动运行的 CLI 程序**的技能，显示安全提示：

```
⚠️ 此技能包含可执行代码 / 自动运行程序
请谨慎确认是否执行。执行后任务可继续；若拒绝，任务可能终止。
```

要求：
- 检测方式：技能目录中存在脚本文件（`.js` `.py` `.sh` `.bat` 等）或 SKILL.md 中声明了命令时，标记该提示
- 只做**提示展示**，不做强制确认弹窗
- 小白用户看不懂代码没关系，但提示要让用户知道"这个技能能自动运行程序"
