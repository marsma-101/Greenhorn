## 一、问题

目前的 `start.bat` 假设用户已经装了 Node.js。但小白用户电脑上什么都没有——没有 Node.js、没有 pnpm、甚至不知道什么是"命令行"。

如果双击 `start.bat` → 显示 "未找到 Node.js" → 窗口关闭 → 小白就卡在这了。

## 二、目标

**小白拿到 GreenHorn 后，双击就能跑起来，不需要自己安装任何东西。**

如果不能做到完全零安装，至少要做到：**缺什么自动引导安装，每一步用户都知道发生了什么、下一步该做什么。**

## 三、需要评估的方案

### 方案 A：打包便携版 Node.js（推荐 MVP）

在项目发布时，把 Node.js 的可执行文件打包进来：

```
GreenHorn 发布包/
├── start.bat                  ← 桌面入口
├── GreenHorn 使用指南.txt      ← 说明文件
├── node/                      ← 便携版 Node.js（~40MB）
│   ├── node.exe
│   └── ...
└── packages/                  ← 编译后的项目代码
    ├── backend/dist/
    └── frontend/dist/
```

`start.bat` 直接用 `node\node.exe packages\backend\dist\index.js` 启动，不需要系统安装 Node.js。

**优点**：真·双击即用
**缺点**：发布包体积增加 ~40MB

### 方案 B：自动下载 Node.js

`start.bat` 检测到没有 Node.js 时，自动下载并安装：

| 尝试顺序 | 方式 | 说明 |
|---------|------|------|
| ① | `winget install OpenJS.NodeJS.LTS` | Windows 10/11 自带，静默安装 |
| ② | 下载 zip 包解压到本地目录 | 不装到系统，只供 GreenHorn 用 |
| ③ | 打开下载页面 | 以上都不行时，引导用户手动下载 |

**优点**：发布包体积小
**缺点**：首次启动需要联网下载，花时间

### 方案 C：像其他正式软件一样发安装包（长远方案）

用 Electron / Tauri 打包成真正的桌面应用——用户下载安装程序，双击安装，桌面上出现一个图标，点击就开。这应该是正式版的目标，MVP 暂时可跳过。

## 四、应该怎么做（供 Trae 评估）

1. 先评估方案 A 的可行性——便携版 Node.js 是否可分发、是否涉及许可问题
2. 如果方案 A 可行，改 `start.bat` 优先查找同目录下的 `node/node.exe`，找不到再回退到系统 PATH
3. 给出 MVP 阶段你认为最合适的方案和实施计划

## 五、验收标准

| # | 条件 |
|---|------|
| 1 | 一台全新的 Windows 电脑，没有安装任何开发工具 |
| 2 | 拿到 GreenHorn 发布包，解压 |
| 3 | 双击 `start.bat` → 能成功启动 GreenHorn |
| 4 | 整个过程不需要用户手动装 Node.js、pnpm 或任何其他工具 |
