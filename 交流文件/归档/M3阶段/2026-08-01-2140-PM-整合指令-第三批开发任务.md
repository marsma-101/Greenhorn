## 二、本批任务清单

### 任务 1：网页安装器（原 A2）

**需求**：单个 HTML 文件（`安装 GreenHorn.html`），从 GitHub/镜像拉取项目，模拟用户全新安装。

**三种方式**（方案 C）：
| 方式 | 说明 |
|------|------|
| 下载 zip | 从 GitHub codeload/镜像下载 greenhorn.zip，解压即可 |
| 下载 install.bat | 生成 bat 放目标文件夹双击 → 自动克隆+装依赖+启动 |
| 复制命令 | git clone 命令（含镜像版本） |

**拉取降级**：GitHub 直连 → gh-proxy.com → ghfast.top（每来源 15s 超时）。

**页面提示**："请先把本文件放到想保存项目的文件夹"。

**注意**：仓库地址需确认（公开仓库 greenhorn 的 owner）。

### 任务 2：对话页智能体标识（原 A6）

**需求**：对话页**左上角**显示当前智能体标识（图标+名称+一句话描述），为多智能体运行预留入口。

**关键点**：
- ChatPage 需新增读取 `?engine=` URL 参数（目前未读）
- 无参数默认显示 PI
- 顶部常驻（滚动可见）
- 「切换 ▾」占位（点击提示"多智能体切换开发中"）
- 主题自适应（CSS 变量）

### 任务 3：A5 引擎验证（Hermes 实测）

**需求**：Hermes 引擎完整验证——能启动、能通过 GreenHorn 对话。

**验证步骤**：
1. Hermes 已装（ai-agent/hermes/program）✅
2. 启动 Hermes（参考《引擎接入手册》）
3. 通过 GreenHorn 对话页选 Hermes → 发消息 → 能回复
4. 记录：启动命令、API 形态、对话成功/失败、问题清单

**交付**：《Hermes 验证报告》

### 任务 4：settings 自动保存（遗留 P1）

**需求**：设置页所有修改立即同步后端，不设"保存"按钮。

- 输入框防抖（500ms）自动 PUT
- 下拉/开关即时保存
- 保存失败提示但不丢输入

### 任务 5：多引擎适配层 B1（启动）

**需求**：完善 EngineAdapter + 能力分级，先验证 PI + Hermes 两个引擎可切换对话。

**内容**：
| 项 | 说明 |
|----|------|
| EngineCapabilities | streaming/thinking/toolCalls/fileOps/scriptExec/contextLimit |
| Adapter 完善 | PI Adapter（已有 chat-engine 封装）+ Hermes Adapter（新写） |
| 统一协议 | 通过 adapter 的 sendMessage() 返回统一事件流 |
| 前端适配 | 引擎能力不同时自动隐藏/降级 UI |
| 验收 | 前端切换 PI/Hermes 对话体验一致 |

### 任务 6：M4 剩余项——start.bat 中文错误提示（自 M3 转入）

**背景**：M3 已正式关闭，其 P2「中文人话错误提示」部分未完成——对话/API 层错误已中文化（chat-engine 已有"API Key 好像不对哦"等映射），但 **start.bat 启动脚本仍是英文**。

**需求**：启动脚本（start.bat / launcher.js / release.ps1）所有用户可见的提示中文化，按小白铁律"失败必须导向动作"：

| 现状（英文） | 改为（中文） |
|-------------|-------------|
| `[ERROR] Node.js not found. Please install: https://nodejs.org/` | `[错误] 找不到 Node.js，请到这里下载安装：https://nodejs.org/` |
| `[ERROR] Build failed. Check network and try again.` | `[错误] 编译失败，请检查网络后重新运行` |
| `[ERROR] Backend build failed.` | `[错误] 后端编译失败` |
| `[ERROR] Port 1001 in use`（如有） | `[错误] 端口 1001 被占用，请关闭占用程序后重试` |

**注意**：
- .bat 文件中文需注意编码（UTF-8 + chcp 65001，参考现有 start.bat 的做法）
- 扫描全部启动链脚本（start.bat / launcher.js / 可能的 release.ps1 输出），所有用户可见英文提示都中文化
- 遵循"失败必须导向动作"：报错后告诉用户"那我现在该点哪/装哪"

**验收**：全新环境模拟（无 Node.js）双击 start.bat → 看到中文错误 + 下载链接指引
