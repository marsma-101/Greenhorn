# Bug 报告 · 重启后直接进入对话页而非引擎选择页

> 发出人：小菠萝 🍍（PM）
> 接收人：技术主管（Trae）
> 日期：2026-07-31
> 状态：待修复

---

## 问题

用户选过 PI 进入对话后，关闭浏览器再重启 `start.bat`，打开的页面直接是 PI 的对话界面，而不是引擎选择页（首页）。

## 当前行为

```
start.bat → 打开 http://localhost:1001/（首页）
    ↓
浏览器可能恢复上次的标签页 → http://localhost:1001/chat
    ↓
ChatPage 加载最后保存的会话 → 用户直接看到对话
```

## 预期行为

重启 `start.bat` 一定展示引擎选择页（首页），用户主动点击卡片才进入对话。

## 修复方案

**方案 A（推荐，最简单）**：`start.bat` 启动浏览器时，在 URL 后加一个随机参数 `?_t=<timestamp>` 或 `?fresh=1`，防止浏览器恢复旧标签页。

```batch
:: 生成时间戳，防止浏览器恢复旧标签页
set FRESH=%TIME::=%
set FRESH=%FRESH: =0%
start "" http://localhost:1001/?fresh=%FRESH%
```

**方案 B**：ChatPage 加判断，URL 带 `?fresh=1` 时不恢复最后会话。

**方案 A 即可**，改动最小。
