## 第一步：M3 收尾（P2 中文错误提示）

把项目里所有用户能看到的错误提示改成中文大白话。

### 需要改的范围

| 文件 | 当前文案 | 改为 |
|------|---------|------|
| 后端所有 API 路由 | 英文 error message | 中文人话 |
| start.bat | `[ERROR] Node.js not found. Please install` | `未找到 Node.js，请下载安装` |
| start.bat | `[ERROR] Build failed` | `编译失败，检查网络后重试` |
| 前端所有 catch 块 | `Error: ...` | `出了点小问题，请再试一次` |
| chat-engine.ts | `API request failed` | `请求失败，请检查 API Key 或网络` |
| chat-engine.ts | `network connection interrupted` | `网络连接中断，检查网络后重试` |

### 原则

- 错误信息必须**说用户听得懂的话**
- 不要说技术细节（不说 `401`、`ERR_MODULE`、`fetch failed`），说发生了什么 + 该怎么办
- 如果是用户操作问题（如 Key 不对），直接告诉用户怎么解决
- 如果是系统内部错误，说"出了点小问题" + 建议重试
