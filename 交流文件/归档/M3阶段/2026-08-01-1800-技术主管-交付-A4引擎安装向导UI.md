## 二、A4 实现内容

### 2.1 EngineInstallModal 组件

**文件**：[EngineInstallModal.tsx](file:///d:/program/GreenHorn/packages/frontend/src/components/EngineInstallModal.tsx)

**核心功能**：

| 功能 | 说明 | 状态 |
|------|------|------|
| 安装方式选择 | 本地安装（优先）/ 远程下载 | ✅ |
| 引擎信息展示 | 名称、依赖类型、本地路径 | ✅ |
| 强制重新安装选项 | reinstall checkbox | ✅ |
| 安装进度显示 | 进度条 + 步骤列表（6 阶段） | ✅ |
| 安装完成反馈 | 成功/失败 + 重试/关闭按钮 | ✅ |
| ESC 快捷键关闭 | 仅在 info 阶段可用 | ✅ |
| 点击背景关闭 | 仅在 info 阶段可用 | ✅ |

**四阶段 UI 状态**：

1. **info** - 安装配置
   - 引擎信息卡片
   - 安装方式选择（本地/远程）
   - 强制重新安装选项
   - "开始安装"按钮

2. **installing** - 安装进度
   - 大进度条（百分比实时显示）
   - 步骤列表（检查环境 → 拉取源码 → 安装依赖 → 配置环境 → 完成）
   - 当前步骤高亮

3. **done** - 安装完成
   - 🎉 庆祝动画
   - 安装路径展示
   - "开始对话"快捷按钮

4. **error** - 安装失败
   - 错误信息展示（支持多行）
   - "重试"/"取消"按钮

### 2.2 HomePage 集成

**文件**：[HomePage.tsx](file:///d:/program/GreenHorn/packages/frontend/src/pages/HomePage.tsx)

**修改内容**：

| 修改项 | 说明 |
|--------|------|
| 导入 EngineInstallModal | 新增组件导入 |
| 新增 installingEngine 状态 | 跟踪当前安装的引擎 |
| 修改 handleEngineClick | 未安装引擎 → 打开安装对话框（而非跳转 setup 页） |
| 新增 handleEngineInstalled | 安装成功后更新引擎状态为 ready |
| 添加 EngineInstallModal 组件 | 根据状态条件渲染 |

**交互流程**：
```
首页 → 点击引擎卡片
  ├─ 已就绪 → 跳转 /chat?engine=xxx
  └─ 未安装 → 弹出安装对话框
       ├─ 选择安装方式 → 开始安装
       ├─ 显示安装进度
       └─ 安装完成 → 更新状态为已就绪 → 可点击进入对话
```
