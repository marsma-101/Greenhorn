## 第三阶段规划初稿

### 核心交互改版：标签式侧边栏

```
┌─────────────┬──────────────────────────────┐
│  侧边栏     │  对话区域（一张纸）            │
│  (隐藏/固定) │                              │
│             │  用户写一段话...               │
│ 📄 对话管理 │  AI 回复写在这里...            │
│ ⚙️ 模型设置  │                              │
│ 🤖 智能体   │                              │
│ 🎨 外观     │                              │
│ 📁 工作台   │                              │
│ ⚡ 高级     │                              │
│             │                              │
│ [📌 固定]   │  输入框: [              ] [发] │
└─────────────┴──────────────────────────────┘
```

**设计理念**：
- 整个界面 = 桌面
- 对话区域 = 一张纸，用户和 AI 在纸上交流
- 左侧侧边栏 = 标签页，平时收起，点标签滑出
- 每个标签打开一个设置界面，像翻书一样
- 可固定侧边栏，固定后可以边设左边和右边对话

**标签清单**：

| 标签 | 内容 |
|------|------|
| 📄 对话管理 | 会话列表、切换、改名、删除 |
| ⚙️ 模型设置 | 供应商选择、Key管理、模型选择（当前设置在页） |
| 🤖 智能体 | 角色设定、预设模板 |
| 🎨 外观 | 主题、显示设置 |
| 📁 工作台 | PI 工作目录文件管理 |
| ⚡ 高级 | thinkingLevel、compaction、sessionDir 等 |

**对话页新增功能**：
- 输入框上方：模型下拉（已注册的模型直接切换）
- 输入框上方：智能体身份下拉（切换不同角色）
- 已实现的 📎 文件选择器保留
