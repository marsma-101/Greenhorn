## 二、第三阶段 UI 改版——收到，技术评估

### 整体判断

改版方向合理，从「路由跳转式」改为「侧边栏标签式」是主流 AI 对话产品的标准布局（参考 ChatGPT、Claude）。技术上完全可行。

### 工作量拆解

| 模块 | 工作内容 | 复杂度 |
|------|----------|--------|
| **布局重构** | 新建 Layout 组件，侧边栏 + 主内容区 | 中 |
| **侧边栏组件** | 收起/展开动画、固定按钮、标签切换 | 中高 |
| **标签内容迁移** | 6 个标签页，从现有页面抽取内容 | 中 |
| **对话区改版** | 纸张式视觉风格 | 低（CSS 调整） |
| **工具栏新增** | 模型下拉 + 身份下拉 | 中 |
| **路由调整** | 从多页面路由改为单页面 + 侧边栏 | 低 |

### 技术方案

#### 1. 布局结构

```
App.tsx
├── MainLayout.tsx          ← 新建：整体布局
│   ├── Sidebar.tsx         ← 新建：标签侧边栏
│   │   ├── TabButton.tsx   ← 标签按钮
│   │   └── TabPanel.tsx    ← 标签内容面板
│   └── ChatArea.tsx        ← 改造：纸张式对话区
│       ├── MessageList.tsx ← 消息列表
│       ├── ToolBar.tsx     ← 新建：模型/身份下拉
│       └── InputBar.tsx    ← 输入框 + 文件按钮
```

#### 2. 侧边栏交互

- 收起状态：宽度 48px，只显示图标列
- 展开状态：宽度 280px，滑出动画 0.3s
- 固定模式：📌 按钮切换，固定后不自动收起
- 标签切换：点击标签 → 面板内容切换

#### 3. 标签内容迁移映射

| 标签 | 来源 | 迁移方式 |
|------|------|----------|
| 📄 对话管理 | ChatPage 会话下拉菜单 | 抽取为独立面板 |
| ⚙️ 模型设置 | SettingsPage 模型区块 | 抽取模型相关 section |
| 🤖 智能体 | SettingsPage 智能体区块 | 抽取 persona 相关 section |
| 🎨 外观 | SettingsPage 外观区块 | 抽取主题 + 思考开关 |
| 📁 工作台 | 新建 | PI 工作目录文件浏览（后续实现） |
| ⚡ 高级 | AdvancedSettingsPage | 整页迁移为面板 |

#### 4. 对话页工具栏

输入框上方新增一行：
```
[📎 文件]  [模型: DeepSeek V3 ▾]  [身份: 代码专家 ▾]  [⚡ 加速]
```

- 模型下拉：从 `/api/config` 读取当前 provider，显示该 provider 的模型列表
- 身份下拉：从 `/api/settings` 读取 persona，支持快速切换
