## 二、修复细节

### 2.1 目录结构（PI 原生规范）

```
~/.pi/agent/sessions/
├── --d--program-GreenHorn--/           # 按 cwd 分目录
│   ├── 2026-07-30T16-12-06Z_d854a23b-...jsonl
│   ├── 2026-07-30T23-25-53Z_845e14b9-...jsonl
│   └── 2026-07-31T04-09-08Z_df984ecc-...jsonl
├── --C--Users-Administrator--/          # PI 原生已有
└── ...
```

**cwd → 目录名映射规则**：
```
D:\program\GreenHorn → --d--program-GreenHorn--
C:\Users\Administrator → --C--Users-Administrator--
```
规则：盘符冒号→连字符，反斜杠→连字符，首尾加 `--`

### 2.2 自动检测项目根目录

新增 `findGreenHornRoot()` 函数：
- 从 `process.cwd()` 向上查找 `start.bat` 或 `pnpm-workspace.yaml`
- 最多向上遍历 5 层目录
- 找不到则回退到 `process.cwd()`

### 2.3 Session 行格式（PI v3）

