## 二、M3 任务清单

### P0：便携版 Node.js

**目标**：没有 Node.js 的电脑上，双击 start.bat 也能启动。

**实现思路**：

```
GreenHorn 发布包/
├── start.bat
├── node/                  ← 打包便携版 Node.js
│   └── node.exe
├── packages/backend/dist/
├── packages/frontend/dist/
└── ...
```

`start.bat` 启动时，优先使用同目录下的 `node/node.exe`：

```batch
:: 先找便携版 Node
if exist "%~dp0node\node.exe" (
    set "NODE_PATH=%~dp0node"
) else (
    :: 回退到系统 PATH
    node --version >nul 2>&1
    if errorlevel 1 (
        echo 找不到 Node.js，请下载：https://nodejs.org/
        pause & exit /b 1
    )
)
```

**注意事项**：
- 便携版 Node.js 可从官方下载 zip 包解压，免安装
- 注意 x64 版本，约 40MB
- 打包进发布脚本（scripts/release.ps1）

### P1：安装引导界面

**目标**：第一次打开 GreenHorn，看到一个友好的引导流程。

**流程**（之前已设计，直接复用）：

```
① 欢迎页 → ② 选引擎（PI/更多） → ③ 选保存位置
→ ④ 自动拉取（进度条） → ⑤ 配模型 → ⑥ 开始对话
```

**前端**：新增 `SetupWizardPage.tsx`，4-5 步向导
**后端**：`POST /api/setup/install`（SSE 流式进度）+ `GET /api/setup/check-env`

UI 布局参考 `2026-07-28-PM-前端UX设计需求.md` 中的设计稿。

### P1：模型 API 引导页

**目标**：用户配置 API Key 时有完整的界面引导，不是直接扔一个输入框。

**交互**（已确认的方案）：

```
选择供应商 → 模型联动更新 → URL 自动填充
→ "还没 Key？[一键跳转注册页]"
→ 粘贴 Key → 验证连接
```

**数据**：供应商预设数据在 `model-providers.ts` 已有，前端直接调用 `/api/model-providers`。

### P2：中文人话错误提示

**目标**：所有用户能看到的错误提示，改成中文大白话。

| 当前文案 | 改为 |
|---------|------|
| `Error [ERR_MODULE_NOT_FOUND]` | 系统运行异常，请联系开发 |
| `404 Not Found` | 页面不存在，可能是地址有误 |
| `Failed to fetch` | 网络连接失败，检查网络后重试 |
