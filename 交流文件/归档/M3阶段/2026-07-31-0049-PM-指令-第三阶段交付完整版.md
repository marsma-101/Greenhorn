## 第三部分：UI 改版设计

### 核心思路：多主题样式，不固定一种风格

**不做单一固定样式。** 改为**多主题系统**——设置里可选不同 UI 风格，当前基础版保留为"默认"主题，后续逐步增加其他主题。

**第一期先做一个「Claude 风格」主题**作为第一套备选方案。

### 主题切换入口

设置页 → 外观 → 新增「界面风格」下拉：

```
🎨 外观

界面风格: [ 默认 ▾ ]   ← 新增
           默认
           Claude 风格
           （后续：ChatGPT / 豆包 / DeepSeek ...）

主题:      [浅色] [深色] [跟随系统]
```

默认主题 = 当前已有的 UI 样式，保持不变。

### 第一期：Claude 风格主题

参考 [Claude.ai](https://claude.ai) 的视觉风格，做一套 CSS 主题：

| 维度 | Claude 风格的要求 |
|------|-----------------|
| 配色 | 米白暖底色（#F5F0EB）代替纯白，陶土橙（#C45B3C）作强调色 |
| 字体 | 系统衬线字体优先，标题用 serif |
| 圆角 | 偏小圆角（6-8px），不是大圆角 |
| 卡片 | 对话框像卡片一样浮在暖色背景上，带轻微阴影 |
| 输入框 | 圆角输入框，浅色边框，焦点态淡橙色发光 |
| 消息样式 | 用户消息右对齐暖色气泡（#E8E0D5），AI 回复左对齐白色气泡 |
| 侧边栏 | 暖灰底色，当前标签高亮用陶土橙 |
| 间距 | 偏宽松，左右留白多 |
| 过渡 | 淡入淡出，速度偏慢（0.3s） |

### ⚠️ 重要约束

**只改样式，不改功能、不改布局、不改组件逻辑。**
**基础样式（默认主题）完全不动。** 所有改动只发生在 Claude 主题的 CSS 变量覆盖中。

具体来说：
- ✅ 默认主题：保持原样，不动任何代码
- ✅ Claude 主题的 CSS 变量改颜色、字体、间距、边框半径、阴影
- ✅ **Claude 主题中用 SVG 图标替换 emoji**（默认主题继续用 emoji）
- ❌ 不改组件渲染逻辑
- ❌ 不改消息结构
- ❌ 不改侧边栏展开/收起逻辑
- ❌ 不改输入框功能

实现方式：用 CSS 变量（`--color-bg`, `--color-card`, `--color-accent`, `--icon-xxx` 等）。不同主题只切换变量值，不写两套组件。默认主题的 emoji 保留不动，Claude 主题通过 CSS 变量或条件渲染替换为 SVG。

- hover 时颜色平滑过渡 0.2s

### 参考产品 UI 分析

以下是当前主流 AI 聊天产品的界面设计特点，供 UI 设计时参考：

#### Claude（最佳参考）

| 维度 | 特点 |
|------|------|
| 布局 | 双栏：左侧对话 + 右侧 Artifacts 面板 |
| 配色 | 米白暖底色，陶土橙点缀，低饱和色彩体系 |
| 字体 | 衬线体为主，营造"阅读感"和"创作感" |
| 消息样式 | 三段式：思考过程（🧠 可折���卡片）+ 工具调用 + 最终回复 |
| 交互亮点 | 选中文本可直接追问、Artifacts 工件可编辑/分支版本 |

#### ChatGPT

| 维度 | 特点 |

| 配色 | 白底 + 绿色强调，深色/浅色主题分离清晰 |

### 设计方向建议

以 **豆包的圆润柔和风格** + **Claude 的双栏布局和消息分段样式** 为主要参考方向：

| 设计元素 | 参考来源 | 说明 |
|----------|---------|------|
| 整体圆润感 | 豆包 | 大圆角卡片、柔和配色、毛玻璃效果 |
| 消息三段式 | Claude | 思考/工具/回复 视觉清晰区分 |
| 侧边栏布局 | Claude/ChatGPT | 标签式可隐藏侧边栏，结合左侧标签面板 |
| 输入框工具栏 | ChatGPT | 📎 文件 + 模型下拉 + 身份下拉 一行排列 |
| 配色参考 | Claude 暖色系 | 米白底色 + 低饱和强调色，长时间阅读舒适 |

### 具体视觉要求

1. **配色**：主色绿色系（呼应 "Green"Horn），辅色低饱和，不要花哨
2. **圆角**：卡片 12-16px，按钮 8-12px
3. **字体**：系统默认字体 `-apple-system`，行距舒适
4. **间距**：统一 4px 基准间隔体系
5. **按钮**：主要操作填色，次要操作为线框或文字按钮
6. **输入框**：圆角，焦点态有发光边框
7. **过渡动画**：侧边栏滑出 0.3s ease，hover 变色 0.2s
8. **阴影**：轻阴影，卡片间有层次感
