## 一、交付内容

### 1.1 首页引擎卡片布局

**改动前：** 首页直接显示 ChatPage（聊天界面），无引擎选择入口。

**改动后：** 首页（`/`）显示引擎选择页，包含以下元素：

| 区域 | 内容 |
|------|------|
| 顶部标题 | 🍃 GreenHorn + 副标题「选择一个智能体来对话」 |
| 引擎卡片网格 | 6 张卡片（自适应网格布局，auto-fill minmax(200px, 1fr)） |
| 更多引擎入口 | 「➕ 更多引擎 · 开发中」（灰色禁用状态） |
| 使用指南 | 底部「怎么用？」链接，点击弹出 3 步使用说明 |
| 欢迎弹窗 | 首次进入时弹出欢迎引导（可关闭） |

### 1.2 六张引擎卡片

| # | 引擎 | Emoji | 描述 | 状态策略 |
|---|------|-------|------|----------|
| 1 | PI | 🍍 | 本地优先，项目级 AI Agent | 动态检测（调 `/api/pi/`） |
| 2 | Hermes | 🔵 | 轻量本地，专注代码补全 | 静态：未安装 |
| 3 | Claude Code | 🟡 | Claude 官方 AI Agent | 静态：未安装 |
| 4 | Codex | ⚪ | OpenAI 官方 Codex | 静态：未安装 |
| 5 | OpenCode | 🟣 | 开源多模型 AI Agent | 静态：未安装 |
| 6 | Reasonix | 🔴 | 深度推理型 AI Agent | 静态：未安装 |

> 注：按 PM 决定「S1 先静态，S2 后补动态」，除 PI 外其余引擎状态为静态占位，S2 时补充真实安装检测。

### 1.3 路由变更

| 路径 | 改动前 | 改动后 |
|------|--------|--------|
| `/` | ChatPage | **HomePage（引擎选择）** |
| `/chat` | ❌ 不存在 | ✅ ChatPage |
| `/settings` | SettingsPage | SettingsPage（不变） |
| `/settings/advanced` | AdvancedSettingsPage | AdvancedSettingsPage（不变） |
| `/setup` | SetupWizardPage | SetupWizardPage（不变） |
| 其他 | 不变 | 不变 |

### 1.4 交互逻辑

- **就绪卡片**（如 PI 已安装）：点击 → 跳转 `/chat?engine=pi`
- **未安装卡片**：点击 → 跳转 `/setup?engine=xxx`（引导安装）
- **状态标签**：就绪（绿）/ 安装中（黄）/ 未安装（灰），沿用现有 CSS 类

## 二、实现细节

### 2.1 改动的文件

| 文件 | 改动类型 | 说明 |
|------|----------|------|
| `packages/shared/src/constants/index.ts` | 修改 | 新增 `EngineInfo` 类型，`ENGINES` 从对象改为数组（6 个引擎） |
| `packages/shared/src/index.ts` | 修改 | 导出 `EngineInfo` 类型 |
| `packages/frontend/src/pages/HomePage.tsx` | **重写** | 完整重写为引擎选择页 |
| `packages/frontend/src/App.tsx` | 修改 | 路由：`/` → HomePage，新增 `/chat` 路由 |

### 2.2 关键技术决策

1. **ENGINES 数据结构**：从 `{ PI: {...} }` 对象改为 `EngineInfo[]` 数组，便于渲染 6 张卡片
2. **自适应网格**：`grid-template-columns: repeat(auto-fill, minmax(200px, 1fr))` — 宽屏多列、窄屏单列
3. **SVG/Emoji 双模式**：卡片 emoji 图标遵循 `useSVG` 设置（SVG 图标或 emoji）
4. **状态动态检测**：PI 卡片通过 `fetch('/api/pi/')` 实时检测安装状态，其余引擎为静态占位
