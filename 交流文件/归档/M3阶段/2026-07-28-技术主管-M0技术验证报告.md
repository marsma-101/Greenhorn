## 二、PI SDK 详细分析

### 2.1 核心 API：`createAgentSession()`

来源：`packages/coding-agent/src/core/sdk.ts`

```typescript
import { createAgentSession } from '@pi-agent/coding-agent/sdk';

// 最简用法
const session = await createAgentSession({
  model: 'deepseek/deepseek-chat',
  cwd: '/path/to/workspace',
});

// 发送消息
await session.prompt('帮我写一个 React 组件');

// 监听事件
session.on('message_update', (event) => {
  console.log('AI回复:', event.content);
});

session.on('tool_execution_end', (event) => {
  console.log('工具调用完成:', event.toolName, event.result);
});

session.on('agent_end', () => {
  console.log('对话结束');
});
```

### 2.2 事件系统（流式支持）

PI SDK 提供完整的事件流，覆盖对话全生命周期：

| 事件 | 说明 | 对应 UI 展示 |
|------|------|-------------|
| `agent_start` | Agent 开始处理 | 显示"思考中..." |
| `message_update` | AI 消息更新（流式） | 实时显示文字 |
| `tool_execution_start` | 工具调用开始 | 显示工具卡片 |
| `tool_execution_end` | 工具调用结束 | 显示工具结果 |
| `agent_end` | Agent 处理结束 | 显示完成状态 |

### 2.3 AgentSession 关键方法

| 方法 | 说明 |
|------|------|
| `prompt(message)` | 发送用户消息 |
| `steer(message)` | 在流式输出中插入引导消息 |
| `followUp(message)` | 追加后续消息 |
| `on(event, handler)` | 监听事件 |
| `abort()` | 中断当前操作 |

### 2.4 会话管理

- 会话存储：JSONL 格式（`~/.pi/agent/sessions/`）
- 会话操作：创建、打开、列表、删除
- 会话数据：消息历史、工具调用记录、使用情况

## 三、RPC 模式分析（备选方案）

来源：`packages/coding-agent/src/modes/rpc/`

PI 还支持 **JSON-RPC 模式**，通过 stdin/stdout 通信：

```typescript
// 启动 PI 进程（RPC 模式）
const client = new RpcClient();
await client.start({ cwd: '/path/to/workspace' });

// 发送消息
await client.prompt('帮我写代码');

// 监听事件
client.on('message_update', (event) => { ... });
client.on('tool_execution_end', (event) => { ... });
```

**适用场景**：
- 进程隔离（PI 崩溃不影响 GreenHorn）
- 远程驱动（PI 运行在其他机器）
- 多版本共存（不同项目用不同 PI 版本）

### 6.2 Adapter 抽象层设计

```typescript
// 统一引擎接口
interface EngineAdapter {
  name: string;
  version: string;
  
  // 对话能力
  sendMessage(
    prompt: string, 
    context: SessionContext
  ): AsyncIterable<ChatEvent>;
  
  // 配置能力
  getConfig(): EngineConfig;
  updateConfig(config: Partial<EngineConfig>): void;
  
  // 会话管理
  listSessions(): SessionInfo[];
  getSession(id: string): SessionInfo;
  deleteSession(id: string): void;
}

// 事件类型（统一消息模型）
type ChatEvent = 
  | { type: 'text'; content: string }
  | { type: 'thinking'; content: string }
  | { type: 'tool_call'; name: string; input: any }
  | { type: 'tool_result'; name: string; output: any }
  | { type: 'done'; reason: string }
  | { type: 'error'; message: string };

// PI 适配器（方案A：使用 SDK）
class PiAdapter implements EngineAdapter {
  private session: AgentSession;
  
  async *sendMessage(prompt, context) {
    await this.session.prompt(prompt);
    
    for await (const event of this.session.events()) {
      yield this.mapToChatEvent(event);
    }
  }
}

// 自实现对话引擎（方案B：直接调 API）
class LightweightChatEngine implements EngineAdapter {
  async *sendMessage(prompt, context) {
    const response = await fetch(baseUrl + '/v1/chat/completions', {
      method: 'POST',
      body: JSON.stringify({ messages, stream: true })
    });
    
    for await (const chunk of response.body) {
      yield this.parseSSEChunk(chunk);
    }
  }
}
```
