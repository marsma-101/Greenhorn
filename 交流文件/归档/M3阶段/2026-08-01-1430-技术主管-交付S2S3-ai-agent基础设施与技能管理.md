## 二、S3 交付内容：模板 + 技能管理

### 2.1 提示词模板（Prompts）

**后端 API**（已存在，更新存储路径）：
- `GET /api/templates` — 列表（支持搜索和分类筛选）
- `GET /api/templates/categories` — 分类列表
- `GET /api/templates/:id` — 详情
- `POST /api/templates` — 创建
- `PUT /api/templates/:id` — 更新
- `DELETE /api/templates/:id` — 删除

**存储位置**：`ai-agent/pi/data/prompts/`

**前端页面**：`/prompts`
- 模板列表（网格布局）
- 搜索 + 分类筛选
- 新建/编辑/删除模板
- 模板内容实时预览

### 2.2 技能管理（Skills）

**后端 API**（新增扫描/导入功能）：
- `GET /api/skills` — 列表
- `POST /api/skills` — 创建
- `PUT /api/skills/:id` — 更新（支持启用/禁用切换）
- `DELETE /api/skills/:id` — 删除
- **`POST /api/skills/scan`** — 🆕 扫描外部文件夹
- **`POST /api/skills/import`** — 🆕 导入技能文件
- **`POST /api/skills/check-safety`** — 🆕 安全检测
- **`POST /api/skills/import-url`** — 🆕 从 URL 导入

**存储位置**：`ai-agent/pi/data/skills/`

**安全检测**：
- 检测脚本执行指令（shell、bash、execute 等）
- 检测危险操作（delete、rm -rf 等）
- 检测网络请求（curl、download 等）
- 风险等级：low / medium / high
- 返回 warnings 列表提示用户

**前端页面**：`/skills`
- 技能列表（网格布局，显示启用/禁用状态）
- 搜索筛选
- 新建/编辑/删除技能
- **「📂 从文件夹导入」按钮** — 🆕 扫描外部文件夹并导入
- 技能启用/禁用开关

### 2.3 对话页技能按钮

在 ChatPage 输入区域新增「🧰 技能」按钮：
- 显示当前启用的技能列表
- 点击技能可将其 Prompt 插入到输入框
- 与「📝 模板」按钮并列
