## 一、问题修复情况

### ❌ 问题 1（致命）：message 行结构不符合 PI 规范 → ✅ 已修复

**修复前**（扁平结构，PI 解析会读到 undefined）：
```json
{"type":"message","id":"...","parentId":null,"role":"user","content":[{"type":"text","text":"你好"}],"timestamp":"2026-07-31T04:09:08.050Z"}
```

**修复后**（嵌套 message 对象，完全符合 PI v3 规范）：
```json
{"type":"message","id":"ee85eda8-f02d-49b0-86e5-0307ddacfe8b","parentId":null,"timestamp":"2026-07-31T07:01:02.626Z","message":{"role":"user","content":[{"type":"text","text":"你好世界，测试PI格式"}],"timestamp":1785481262626}}
```

**关键改动**：
- `role` 和 `content` 从顶层移入 `message` 对象内
- `message.timestamp` 使用 epoch 毫秒（PI 规范要求）
- 新增 `AgentMessage` 接口定义 message 内部结构

### ❌ 问题 2（方案优化）：用 PI 原生 session_info 存标题 → ✅ 已实现

**废弃**：独立 `titles.json` 元数据文件（已删除）

**改用**：PI 原生 `session_info` 事件存储会话名

**session_info 事件格式**（完全符合 PI 规范）：
```json
{"type":"session_info","id":"264fa570-3fb9-48c2-b571-cdaec14a1a4e","parentId":"ee85eda8-f02d-49b0-86e5-0307ddacfe8b","timestamp":"2026-07-31T07:01:02.626Z","name":"我的测试会话"}
```

**实现逻辑**：
- 创建会话时：首条用户消息自动生成标题，写入 `session_info` 事件
- 手动改名时：追加新的 `session_info` 事件（PI 会取最后一个）
- 读取会话时：从 jsonl 中查找 `session_info` 事件的 `name` 字段

## 三、修复内容汇总

### 代码改动

**文件**：`packages/backend/src/routes/sessions.ts`

**主要变更**：
1. **新增 `AgentMessage` 接口**：定义 message 内部结构（role + content + timestamp 毫秒）
2. **新增 `MessageEvent` 接口**：message 行结构改为 `message` 对象嵌套
3. **新增 `SessionInfoEvent` 接口**：定义会话名称事件
4. **废弃 `TITLES_META_PATH`**：删除 titles.json 相关常量和函数
5. **修改 `reconstructSession()`**：从 `session_info` 事件读取标题，从 `message.role` / `message.content` 读取消息
6. **修改所有 API 路由**：
   - `POST /`：创建会话不变
   - `PUT /:id`：消息写入嵌套 message 对象，首条消息自动生成 session_info
   - `PUT /:id/title`：改为追加 session_info 事件
   - `GET /` 和 `GET /:id`：从 jsonl 直接读取，不再依赖 titles.json
   - `DELETE /:id`：简化为删除 jsonl 文件

### jsonl 格式对比

| 项目 | 修复前 | 修复后 |
|------|--------|--------|
| message 行 role 位置 | 顶层 | `message.role` |
| message 行 content 位置 | 顶层 | `message.content` |
| message timestamp | ISO 字符串 | `message.timestamp` 毫秒 |
| 会话名存储 | titles.json | jsonl 内 `session_info` 事件 |
| 数据源 | 双源（jsonl + titles.json） | 单一数据源（jsonl） |
