## 第一部分：先修 bug

### 问题：重启 start.bat 直接进对话页而不是引擎选择页

用户选过 PI 进入对话后，关闭浏览器再重启 `start.bat`，打开的页面直接是对话界面，而不是首页的引擎选择。

**修复方案**（推荐，改动最小）：`start.bat` 启动浏览器时，在 URL 后加随机参数防止浏览器恢复旧标签页。

```batch
:: 生成时间戳，防止浏览器恢复旧标签页
set FRESH=%TIME::=%
set FRESH=%FRESH: =0%
start "" http://localhost:1001/?fresh=%FRESH%
```

### 1. 标签侧边栏（左侧）

- **默认状态**：收起，只显示一条细的标签列（宽度 48px）
- **展开方式**：点击标签 → 侧边栏滑出（动画 0.3s，展开宽度 280px）
- **固定功能**：侧边栏右上角有 📌 固定按钮，点击后保持展开
- **标签切换**：固定状态下，点击不同标签切换内容，侧边栏不收起
- **关闭方式**：已固定时点 📌 取消固定；未固定时点标签外区域收起

### 2. 标签清单

| 图标 | 标签名 | 内容 |
|------|--------|------|
| 📄 | 对话管理 | 会话列表、切换、改名、删除、新建对话 |
| ⚙️ | 模型设置 | 供应商选择、Key 管理、模型选择 |
| 🤖 | 智能体 | 角色设定、预设模板（当前设置页的智能体设定） |

| ⚡ | 高级 | 当前高级设置页内容（thinkingLevel、compaction、quietStartup 等） |

### 3. 对话区域

- 视觉风格：一张白色/淡色"纸"，圆角，带一点阴影
- 用户消息：写在纸上的文字

- 输入框：纸张底部的输入区域

## 第四部分：UI 视觉风格参考

### 参考样式建议

第三阶段的视觉风格，建议参考以下产品之一的风格。请从中选择一个作为主风格方向：

| 参考产品 | 风格特点 | 适合场景 |
|----------|---------|----------|
| **① 豆包（Doubao）** | 圆润卡片式、柔和配色、大圆角按钮、轻阴影、毛玻璃效果 | AI 对话产品，最接近 GreenHorn 的定位 |
| **② ChatGPT** | 极简对话式、左侧历史列表、深色/浅色主题清晰分离 | 最成熟的 AI 对话 UI 模式 |
| **③ Claude** | 极简主义、干净排版、大留白、纤细字体 | 追求简洁优雅 |
| **④ Perplexity** | 信息型搜索风格、带来源引用、左侧边栏分类 | 偏信息检索场景 |

**推荐方向**：以 **豆包（Doubao）** 的风格为基准——因为它：
- 面向中国用户，视觉语言更接地气
- 圆润柔和，适合"小白友好"定位
- 功能布局（对话 + 设置）与 GreenHorn 最接近

### 具体设计要求

1. **配色**：主色用绿色系（呼应"Green"Horn），辅色适度，不要花哨
2. **圆角**：卡片圆角 12-16px，按钮圆角 8-12px，整体偏圆润
3. **阴影**：轻阴影，卡片之间有层次感
4. **字体**：系统默认字体（`-apple-system`），字号清晰，行距舒适
5. **间距**：统一间距体系（4px 基准），不要忽宽忽窄
6. **按钮**：主要操作按钮填色，次要操作为线框或文字按钮
7. **输入框**：圆角、有焦点态（边框变色、发光）
8. **过渡动画**：侧边栏滑出 0.3s ease、按钮 hover 变色 0.2s
