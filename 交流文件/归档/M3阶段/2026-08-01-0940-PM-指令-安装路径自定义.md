# PM 指令 · 安装路径自定义（不装 C 盘）

> 发出人：小菠萝 🍍（PM）
> 接收人：技术主管（Trae）
> 日期：2026-08-01
> 状态：待执行
> 优先级：P1（与第二批并行）

---

## 需求背景

当前安装引擎时，程序默认安装到 C 盘（`~/.pi/agent` 等路径写死）。用户明确不希望程序装 C 盘（C 盘空间紧张、重装系统丢数据）。

**需求**：安装引导过程中，**询问用户选择安装位置**，再按用户选择的路径进行安装。

---

## 功能设计

### 安装引导界面新增「选择安装位置」步骤

```
安装流程（更新后）：
① 选引擎 → ② 选保存路径（新增）→ ③ 自动拉取+安装 → ④ 配模型 → ⑤ 开始对话
```

### 路径选择界面

```
② 选择安装位置
┌─────────────────────────────────────────┐
│ 📁 程序将安装到：                          │
│ [ D:\ai使用培训\引擎\        ] [浏览...]   │
│                                          │
│ 推荐：D 盘（不占 C 盘空间，重装系统不丢）    │
│                                          │
│ 💾 可用空间：D 盘 剩余 380 GB              │
│                                          │
│ [← 上一步]        [下一步 →]              │
└─────────────────────────────────────────┘
```

### 交互要求

1. **默认路径**：预填推荐路径（如 `D:\ai使用培训\引擎\`），用户可改
2. **🔴 铁律：默认永远不装 C 盘**（新增强调）
   - 默认路径**永远是**非 C 盘（优先 D 盘，D 盘不存在则选剩余空间最大的盘符）
   - 识别到 C 盘已有旧安装时：**不留在 C 盘继续用**，提示"检测到 C 盘旧数据，请迁移到新位置"（走迁移流程，见第四部分）
   - 只有用户**明确手动输入 C 盘路径**时才允许装 C 盘（不拦截，但给出黄色提示"装 C 盘可能占用系统空间，重装系统会丢数据"）
   - 说明：本机测试因历史原因已装 C 盘，属特例；新用户第一次拉取安装必须走非 C 盘默认路径
3. **浏览按钮**：点击弹出系统目录选择器（浏览器原生 `webkitdirectory` 或 Electron 目录对话框）
4. **路径校验**：
   - 路径合法（不能是 C:\Windows 等系统目录）
   - 目标盘有足够空间
   - 目录可写
5. **自动补全**：用户输入不存在的目录时自动创建
6. **记住选择**：安装成功后把路径存到配置，后续升级/重装沿用

### 安装位置的影响范围

| 项目 | 跟随安装位置 | 说明 |
|------|------------|------|
| 引擎程序本体 | ✅ | 如 PI 装到 `<用户选择的路径>/pi/` |
| 配置目录 | ✅ | `settings.json`/`auth.json` 存到 `<用户选择的路径>/config/`（不再用 `~/.pi/agent`） |
| 会话目录 | ✅ | 跟随配置目录 |
| start.bat | ✅ | 启动时读取用户配置的路径 |

### 迁移

如果用户之前已经装过（旧数据在 `~/.pi/agent`），安装新版本时提示：
```
检测到旧版配置在 C:\Users\xxx\.pi\agent
是否迁移到新位置？ [迁移] [不迁移]
```
迁移 = 复制配置目录到新位置，旧位置保留不动（可手动删除）。

## 四、数据迁移（重要补充：重装系统不丢数据）

### 需求背景

用户最怕的场景：**重装系统后所有数据丢失**（设置、API Key、提示词模板、技能、聊天记录全没了）。需要提供完整的数据迁移能力，让重要数据可备份、可恢复。

### 需要迁移的数据清单

| 数据 | 位置 | 重要性 |
|------|------|--------|
| 设置 | settings.json | 🔴 高 |
| API Key | auth.json | 🔴 高（迁移后免重新配置） |
| 提示词模板 | prompts/*.md | 🔴 高（用户自建资产） |
| 技能 | skills/ | 🔴 高（用户自建资产） |
| 聊天记录 | sessions/*.jsonl | 🔴 高 |
| 主题 | themes/ | 🟡 中 |
| 扩展 | extensions/ | 🟡 中 |

### 三种触发场景

#### 场景 1：安装时检测旧数据
安装引导选完路径后，若检测到 C 盘旧配置：
```
检测到旧版数据在 C:\Users\xxx\.pi\agent
包含：设置 / API Key / 提示词模板 / 技能 / 聊天记录
是否迁移到新位置？ [迁移] [不迁移]

迁移后旧数据保留在原处，确认无误后可手动删除。
```

#### 场景 2：程序内手动迁移（设置页）
设置页新增「数据管理」区块：

```
📦 数据管理
当前数据位置：D:\ai使用培训\引擎\config\
[更改位置] [备份数据] [从备份恢复]

⚠️ 更改位置会把设置/Key/模板/技能/聊天记录全部复制到新位置
```

#### 场景 3：重装系统后恢复
程序启动时**检测不到配置目录**（说明是新系统/数据丢失），引导：
```
未检测到 GreenHorn 数据。
如果之前有备份，请选择备份位置恢复：
[选择备份位置并恢复] [全新开始]

恢复后：设置 / API Key / 模板 / 技能 / 聊天记录 全部还原
```

### 迁移实现要求

| 项 | 要求 |
|----|------|
| 迁移方式 | 整个配置目录复制（文件复制，不改程序逻辑） |
| 原子性 | 先复制到临时目录，全部成功后再切换，失败不损坏原数据 |
| 原数据保留 | 迁移后旧位置保留，用户确认后再删 |
| 进度显示 | 迁移过程有进度条（SSE） |
| API Key 安全 | 迁移包含 auth.json，但界面显示时打码 |
| 备份功能 | 可一键打包成压缩文件（zip），供手动保存到其他盘/网盘 |

### 验收标准

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 安装时检测旧数据 | 检测到 C 盘旧配置时出现迁移提示 |
| 2 | 迁移成功 | 新位置出现全部数据（设置/Key/模板/技能/聊天记录） |
| 3 | 迁移后程序可用 | 聊天记录可加载、Key 有效、技能可调用 |
| 4 | 手动迁移 | 设置页可更改数据位置 |
| 5 | 备份/恢复 | 可打包 zip、可从 zip 恢复 |
| 6 | 重装恢复引导 | 无配置目录时出现恢复引导 |
| 7 | 原数据保留 | 迁移后旧位置未删除 |

## 验收标准

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 安装引导有路径选择步骤 | 选引擎后出现路径选择界面 |
| 2 | 可自定义路径 | 手动输入或浏览选择，非 C 盘目录可安装 |
| 3 | 程序真的装到该位置 | 安装后检查文件在用户选择的目录下 |
| 4 | 配置跟随 | settings/auth 文件在用户目录下，不在 `~/.pi/agent` |
| 5 | 路径校验 | 系统目录/无权限目录有中文错误提示 |
| 6 | 记住选择 | 重启后安装路径保持 |
| 7 | 旧配置迁移 | 有提示，可选择迁移或忽略 |
