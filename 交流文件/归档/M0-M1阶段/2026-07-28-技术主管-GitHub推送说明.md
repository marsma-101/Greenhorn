### 方案 2：配置代理

如果你有代理，配置 Git 使用代理：

```bash
# HTTP 代理
git config --global http.proxy http://127.0.0.1:端口号

# HTTPS 代理
git config --global https.proxy http://127.0.0.1:端口号

# 然后推送
git push -u origin main
```

### 方案 3：使用 GitHub CLI

安装 GitHub CLI 后：

```bash
# 登录
gh auth login

# 推送
gh repo view --web
```

### 方案 4：配置 SSH Key

1. 生成 SSH key：
```bash
ssh-keygen -t rsa -b 4096 -C "13820242717@163.com"
```

2. 添加公钥到 GitHub：
   - 复制 `C:\Users\Administrator\.ssh\id_rsa.pub` 内容
   - 访问 https://github.com/settings/keys
   - 点击 "New SSH key"，粘贴公钥

3. 推送：
```bash
git push -u origin main
```
