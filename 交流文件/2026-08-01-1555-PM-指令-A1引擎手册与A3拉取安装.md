## 三、A3：引擎拉取安装功能（子智能体分工）

### 目标

实现项目内的**引擎拉取安装能力**：从 GitHub/镜像拉取 6 个引擎源码到 `ai-agent/<引擎>/`，并完成依赖安装。

### 建议分工（你可以自行调整）

```
主智能体（你）：
  ├─ 设计统一安装流程接口（installEngine(id, targetDir, progressCb)）
  ├─ 整合各子智能体的拉取模块
  ├─ 编写完成报告
  └─ 最终验证

子智能体（并行派发，每个负责一个引擎的拉取模块）：
  ├─ 子智能体 A → Hermes 拉取模块
  ├─ 子智能体 B → Claude Code 拉取模块
  ├─ 子智能体 C → Codex 拉取模块
  ├─ 子智能体 D → OpenClaw 拉取模块
  ├─ 子智能体 E → OpenCode 拉取模块
  └─ 子智能体 F → Reasonix 拉取模块
```

### 每个拉取模块的要求

| 项 | 要求 |
|----|------|
| 拉取来源 | GitHub 直连 → gh-proxy.com → ghfast.top 自动降级（参考调研记录） |
| 目标位置 | `ai-agent/<引擎>/program/`（源码） |
| 依赖安装 | 按引擎实际需要（npm/pnpm/uv/pip 等） |
| 进度上报 | 回调进度（克隆中/装依赖中/完成） |
| 幂等 | 重复安装时提示"已存在，是否覆盖" |
| 失败处理 | 每来源超时 15s 自动降级，全失败返回中文错误 |

### 拉取来源参考

`D:\ai使用培训\GreenHorn拉取参考\智能体拉取链接调研记录.md`（含各引擎 GitHub 地址 + 镜像实测结果）
