## 一、问题

小白用户拿到 GreenHorn 后不知道怎么启动。目前开发用 `pnpm dev`（两个端口），开发人员用着方便，但小白不应该知道这些。

**需要一套"生产模式"启动方案**——桌面一个文件，双击就能用。

### 用户理想体验

```
桌面双击 → 浏览器自动打开 → 看到引擎选择页 → 选引擎 → 开始用
全程不需要理解"端口""localhost""前端""后端"这些词
```

### 现实约束

**浏览器 HTML 文件不能直接启动本地程序**（安全限制），所以必须有一个 .bat 做"点火器"。
目标是把 .bat 的存在感降到最低——窗口一闪而过，用户不需要操作它。

## 二、技术方案

### 整体思路

```
Desktop 双击 GreenHorn.bat
    │
    ▼
第一个黑窗口（自动运行）
    ├── ① 编译前端（首次需要，后续跳过）
    ├── ② NODE_ENV=production
    ├── ③ 启动后端 pnpm start
    └── ④ 打开浏览器 http://localhost:3000
    │
    ▼
浏览器 http://localhost:3000
    ├── 后端 serve 编译后的前端静态文件（dist/）
    └── 用户看到引擎选择页面
```

### 需要做的两件事

#### ① 后端适配：生产模式下 serve 前端

后端 `index.ts` 已有生产模式代码片段，但需要验证和补全：

```typescript
if (process.env.NODE_ENV === 'production') {
  const frontendDist = path.join(__dirname, '../../frontend/dist');
  app.use(express.static(frontendDist));
  app.get('*', (req, res) => {
    res.sendFile(path.join(frontendDist, 'index.html'));
  });
}
```

需要确保：
- `pnpm --filter @greenhorn/backend build` 编译到 `packages/backend/dist/index.js`
- 运行时 `dist/index.js` 能正确找到 `../../frontend/dist/index.html`
- 所有前端路由（`/` `/chat` `/settings` `/data-dir`）都能正确返回前端页面，不是 404

#### ② 启动脚本：scripts/start.bat

放在 `scripts/start.bat`（项目内，进 git），桌面放快捷方式或副本。

**启动逻辑**：

| 步骤 | 内容 | 耗时 | 备注 |
|------|------|------|------|
| ① 检查后端编译 | `if not exist packages/backend/dist/index.js` → 编译后端 | 首次慢，后续跳过 |
| ② 检查前端编译 | `if not exist packages/frontend/dist/index.html` → 编译前端 | 首次 ~30 秒，后续跳过 |
| ③ 启动服务 | `set NODE_ENV=production` + `pnpm --filter @greenhorn/backend start` | 即时 | 用 `/min` 最小化窗口 |
| ④ 打开浏览器 | `start http://localhost:3000` | 5 秒后 | 自动弹出 |

**第二次启动**（编译过的文件不重复编译）：
```
1. 启动后端
2. 等 5 秒
3. 打开浏览器
```
