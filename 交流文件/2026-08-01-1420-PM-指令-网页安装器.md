## 需求背景

用户需要一个**网页安装器**（单个 HTML 文件），让小白用户能把 GreenHorn 项目从 GitHub（或镜像站）拉取到本地。

**用途**：模拟"用户第一次拿到项目"的完整流程，从头测试项目所有功能（全新环境安装）。

**关键**：拉取来源是 **GitHub 或镜像网站**（不是本地文件），仓库为公开仓库 `greenhorn`。

### 拉取来源策略（按优先级降级）

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | GitHub 官方 codeload | `https://codeload.github.com/<owner>/greenhorn/zip/refs/heads/main` |
| 2 | GitHub 官方 git | `https://github.com/<owner>/greenhorn.git` |
| 3 | 镜像 gh-proxy.com | `https://gh-proxy.com/https://github.com/<owner>/greenhorn/archive/refs/heads/main.zip` |
| 4 | 镜像 ghfast.top | `https://ghfast.top/https://github.com/<owner>/greenhorn/archive/refs/heads/main.zip` |

**降级规则**：下载失败时自动尝试下一个来源（每个来源超时 15s）。

### 三种方式的实现

#### 方式一：下载压缩包
- 点击 → 依次尝试上面的 zip 来源（codeload → 镜像）
- 下载 `greenhorn.zip` 到浏览器下载目录
- 页面提示："下载完成后，解压到当前文件夹，双击 start.bat 即可使用"

#### 方式二：下载安装器（install.bat）
- HTML 用 Blob 生成 `install.bat` 并触发下载
- **install.bat 逻辑**（放在目标文件夹双击运行）：
  ```
  ① 检查 git 是否安装 → 没装提示
  ② git clone（按来源优先级降级：github 直连 → gh-proxy → ghfast）
  ③ 检查 node/pnpm → 没装提示（或引导安装）
  ④ pnpm install 安装依赖
  ⑤ 提示"安装完成，双击 start.bat 启动"
  ```
- 页面提示："把 install.bat 放到想保存项目的文件夹，双击即可自动安装"

#### 方式三：复制命令
- 页面显示 git clone 命令 + 镜像命令
- 「复制」按钮复制到剪贴板

## 二、install.bat 详细逻辑

```
@echo off
chcp 65001 >nul
echo === GreenHorn 自动安装器 ===

REM 1. 检查 git
git --version >nul 2>&1
if errorlevel 1 (
  echo [错误] 未检测到 Git，请先安装：https://git-scm.com/downloads
  pause & exit /b 1
)

REM 2. 克隆项目（直连 → 镜像降级）
git clone https://github.com/<owner>/greenhorn.git
if errorlevel 1 (
  echo 直连失败，尝试镜像...
  git clone https://gh-proxy.com/https://github.com/<owner>/greenhorn.git
)
if errorlevel 1 (
  echo 镜像1失败，尝试镜像2...
  git clone https://ghfast.top/https://github.com/<owner>/greenhorn.git
)
if not exist greenhorn\ (
  echo [错误] 克隆失败，请检查网络或开启代理
  pause & exit /b 1
)

REM 3. 检查 node
node --version >nul 2>&1
if errorlevel 1 (
  echo [错误] 未检测到 Node.js，请先安装：https://nodejs.org
  pause & exit /b 1
)

REM 4. 安装依赖
cd greenhorn
call npm install -g pnpm >nul 2>&1
call pnpm install
if errorlevel 1 (
  echo [错误] 依赖安装失败
  pause & exit /b 1
)

REM 5. 完成
echo.
echo ✅ 安装完成！
echo 双击 start.bat 即可启动 GreenHorn
pause
```
