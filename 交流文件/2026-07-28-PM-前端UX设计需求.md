## 一、用户画像：谁是"小白"？

**目标用户不是程序员，是这些真实的人：**

**他们对"好用"的定义**：

- 按钮上写的是人话（不要"提交 Configuration"→ 要"开始对话"）

- 看不懂的选项最好有默认值，不需要我纠结

## 二、核心设计原则

### 原则 1：零命令行

> **不准用户碰终端。不准用户敲命令。一条都不行。**

- 所有操作点鼠标完成
- 安装、配置、启动全部 GUI 化
- 终端窗口纯粹是"后台服务指示灯"，用户不需要理解里面的文字

### 原则 2：每一步都有反馈

> 用户操作后必须在 0.5 秒内得到视觉反馈。

- 点击按钮 → 按钮变"加载中"状态
- 正在下载 → 明确的进度条 + 百分比 + 正在做什么的文案
- 出错了 → 红色提示框 + **用大白话告诉用户发生了什么 + 该怎么办**

### 原则 3：先"一句话"再说详情

> 每个功能/参数先给一句话总结，不要上来就展示全部细节。

- 温度参数 → "控制 AI 的创造力（默认 0.7）" 就够了
- 上下文长度 → "AI 能记住多长的对话（默认 4096）" 就够了
- 想知道更多 → 点旁边的问号(?)展开详情

### 原则 4：容错设计

> 用户的每一步操作都可能是错的，系统要友好地纠正他。

- 输错了 API Key → 不是"Error: Invalid API Key"，是"Key 好像不对哦，试试重新复制粘贴？"
- 网络断了 → 不是"Network Error"，是"网络好像连不上了，等一等再试试"
- 空搜索 → 不是空列表，是"还没有对话记录，开始第一段对话吧！"

### 原则 5：视觉友好

> 不��于技术感的冷硬风格。

- 配色温暖柔和（参考 Notion、Arc 浏览器的风格）
- 字体圆润清晰（推荐系统默认字体 + 适当行距）
- 图标友好（用 emoji 或插画代替纯文字标签）
- 大量留白，不要挤满屏幕

| 错误提示 "401 Unauthorized" | 提示 "Key 好像不对哦，检查有没有复制完整" |

## 四、跨页面通用要求

### 4.1 加载状态

每个页面的每个动作都必须有明确的视觉反馈：

- **按钮点击** → 按钮变禁用，显示旋转动画 + "加载中..."
- **页面加载** → 骨架屏（灰色占位框，不是转菊花）
- **长任务** → 进度条 + 文案说明当前在做哪一步
- **任何超过 3 秒的操作** → 进度条

### 4.2 错误处理

- **不要只显示错误码** → "连接失败了，可能是网络问题，再试一次？"
- **提供可操作的解决方案** → 每个错误提示下至少给一个"你可以试试：..."的建议
- **重试按钮** → 大多数临时性错误下都有重试按钮
- **网络断开** → 显示横幅提示（不影响已加载内容的阅读）

### 4.3 空状态

所有列表/页面首次打开时必须设计空状态，不是"空白"：

- 空会话 → "还没有对话记录，开始第一段对话吧！" + 示例问题
- 空日志 → "还没有活动记录"
- 空搜索 → "没有找到相关内容" + 建议

### 4.4 文案风格

- **全文用中文**，不要中英混杂
- **语气像朋友**，不要像说明书
- **避免技术术语**：不说"实例化"→ 说"创建"；不说"配置环境变量"→ 说"设置"
- **鼓励性**：完成后给 ✅ 或 🎉，不要只说"成功"
- **一致的称呼**：全文统一用"你"，不用"用户"

### 4.5 主题

| 元素  | 浅���主题      | 深色主题    |
| --- | ----------- | ------- |
| 背景  | 白色 / 浅灰     | 深灰 / 近黑 |
| 文字  | 深灰近黑        | 浅灰近白    |
| 主色调 | 绿色/青色系（品牌色） | 同色系暗化版  |
| 卡片  | 白底细阴影       | 深色底浅边框  |
| 代码块 | 浅灰底深灰字      | 深色底浅色字  |

## 五、开发优先级建议

根据简化后的架构（不做 PI 已经能做的事），推荐的页面开发顺序：

| 优先级 | 页面 | 理由 |
|--------|------|------|
| 🥇 **P0** | **对话工作台** | 用户花时间最多的地方，MVP 核心 |
| 🥇 **P0** | **模型 API 引导页** | 没有 API Key 就用不了 |
| 🥈 **P1** | **首页/项目选择 + 安装进度** | 首次使用流程，但只走一次 |
| 🥉 **P2** | **设置面板** | 只有模型切换和主题，非常轻 |

**MVP 明确不做**：
- ❌ 会话浏览/历史记录（PI 自己管理，后期可以用最简单的列表展示）
- ❌ 数据统计仪表盘
- ❌ 高级参数面板（温度/上下文等，PI 默认值运行）
- ❌ 配置导入导出
