## 四、新增重要需求：数据目录可自选

### 背景

PI 的配置文件和会话数据默认存到 `C:\Users\<用户名>\.pi\agent\`，长期使用会占大量 C 盘空间。产品 Owner 要求：**让用户选择文件保存位置，避免自动塞满 C 盘。**

### PI 原生支持方案 ✅

经过查证，PI 的 `getAgentDir()` 函数已支持环境变量覆盖配置路径：

| 方式 | 机制 | 优先级 |
|------|------|--------|
| **环境变量 `PI_CODING_AGENT_DIR`** | 完全覆盖配置目录路径 | **最高** |
| `package.json` 中 `piConfig.configDir` | 改变目录名（`.pi` → 自定义） | 间接影响 |

**这意味着我们可以不碰 PI 源码，直接通过设置环境变量来重定向它的配置目录。**

### 实现方案

#### 用户选择界面

用户在首次使用时看到一个"选择数据目录"的步骤：

```
┌────────────────────────────────────────────┐
│  ← 返回     选择 PI 文件保存位置             │
│                                            │
│  PI 需要存储以下文件：                        │
│  · 配置文件（模型、API Key、设置等）          │
│  · 会话记录                                │
│  · PI 源码（项目代码）                       │
│                                            │
│  默认会存在 C 盘，建议改到其他盘              │
│                                            │
│  PI 项目代码保存位置：                        │
│  [D:\GreenHorn\pi-source\         ] [📁]   │
│                                            │
│  PI 配置数据保存位置：                        │
│  [D:\GreenHorn\pi-config\         ] [📁]   │
│                                            │
│  ┌────────────────────┐                    │
│  │   确认并开始安装      │                    │
│  └────────────────────┘                    │
└────────────────────────────────────────────┘
```

#### 后端实现逻辑

```typescript
// 用户选了两个路径：
const userDataRoot = 'D:\\GreenHornData\\pi-source';   // PI 源码
const userConfigDir = 'D:\\GreenHornData\\pi-config';   // PI 配置

// 1. 克隆 PI 源码到用户选择的路径
await gitClone('https://github.com/earendil-works/pi', userDataRoot);

// 2. 设置环境变量，让 PI SDK 读自定义配置目录
process.env.PI_CODING_AGENT_DIR = userConfigDir;

// 3. 如果发现 C 盘已有旧配置（~/.pi/agent/），提示迁移
if (existsSync('C:\\Users\\xxx\\.pi\\agent')) {
  // 弹提示："检测到 C 盘已有 PI 配置，是否迁移到新位置？"
}
```

### 涉及修改的内容

| 模块 | 影响 |
|------|------|
| A1 前端 | 新增"选择数据目录"页面（步骤 1 选源码路径，步骤 2 选配置路径） |
| A2 后端 | GreenHorn 启动时设置 `PI_CODING_AGENT_DIR` 环境变量；实现旧目录检测提示 |
| A6 文档 | 在部署指南和 FAQ 中说明"数据目录选择"功能 |

### 可行性验证结论 ✅

**PI 原生支持环境变量 `PI_CODING_AGENT_DIR` 覆盖配置目录路径，方案完全可行，不碰 PI 源码。**
