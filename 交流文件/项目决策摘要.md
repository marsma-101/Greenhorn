## 一、项目定位

**开源智能体"产品化外壳"** — 给非程序员使用的零门槛 AI 智能体网页界面。
只做 PI 做不到的事（网页 UI），不做 PI 已能做���事（会话、配置、工具调用）。

---

## 二、架构决策

| 决策 | 结论 | 说明 |
|------|------|------|
| 后端 | **轻量 Web Server**（~200行） | 不建 SQLite、不自己管会话。3 个 API 端点：对话/配置/检测 |
| 前端 | **React 18 + Vite + Tailwind** | 4 个页面 + 设置抽屉，不做仪表盘和统计 |
| 通信 | **SSE** | 流式对话，浏览器原生支持 |
| 对话引擎 | **方案B（轻量引擎）** | 直接调 OpenAI 兼容 API，M1 先用 Ollama 验证，后期可切方案A（PI SDK） |
| 数据存储 | **PI 自有机制** | 配置文件 auth.json/models.json 直接读写，不建独立数据库 |
| 模型供应商 | **硬编码预设** | 7 家供应商预置到代码中，MVP 不搞配置文件覆盖 |
| 数据目录 | **用户自选** | 通过环境变量 `PI_CODING_AGENT_DIR` 重定向 PI 配置路径 |

## 四、关键约束（不可违反）

1. **不绑定 PI** — Adapter 层抽象，换引擎换 Adapter 文件即可
2. **不碰源码** — 不修改任何开源项目（PI、Ollama 等）的原始代码
3. **不做 PI 已有的** — 会话管理、数据统计、参数面板等 PI 自带的功能不重复造
