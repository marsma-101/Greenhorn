## 一、子智能体总览

本项目采用 **多智能体协作** 模式开发，技术主管统一调度，各子智能体分工明确。

| 编号 | 智能体名称 | 角色定位 | 核心职责 |
|------|-----------|---------|---------|
| A1 | **前端开发智能体** | 专业前端工程师 | 页面开发、UI组件、对话界面、tooltip帮助系统 |
| A2 | **后端开发智能体** | Node.js后端工程师 | API服务、PI驱动对接、镜像拉取、配置读写 |
| A3 | **PI引擎对接智能体** | PI源码研究员 | 研究PI源码，确定网页驱动PI的机制，编写Adapter层 |
| A4 | **UI/UX设计智能体** | UI设计师 | 页面设计、交互设计、主题系统、响应式布局 |
| A5 | **测试智能体** | QA工程师 | 单元测试、集成测试、端到端测试、小白用户场景验证 |
| A6 | **文档智能体** | 技术文档工程师 | README、API文档、部署指南、模型API引导教程文案 |
| A7 | **DevOps智能体** | 运维/发布工程师 | GitHub发布、CI/CD、镜像源管理、一键安装脚本 |

## 二、各智能体详细设定

### A1 - 前端开发智能体

**角色设定**：
- 专业前端工程师，精通 React/Vue + TypeScript
- 擅长将设计稿还原为高保真页面
- 关注无障碍访问（a11y）和用户体验

**能力要求**：
- 前端框架：React 18+ / Vue 3（待定，建议React，生态更成熟）
- 语言：TypeScript
- 样式：Tailwind CSS 或 Ant Design
- 状态管理：Zustand / Redux Toolkit
- 流式渲染：SSE / WebSocket 客户端
- 复用基座：能读懂并改造 pi-web-switch 的前端代码

**具体任务**：
1. 首页/项目选择页
2. 对话工作台（消息流、输入框、运行/停止、流式渲染）
3. 配置面板（复用 pi-web-switch 基座改造）
4. 模型API引导教程页（分步图文）
5. 问号tooltip帮助组件（全局可开关）
6. 设置面板（主题切换、说明开关）
7. 会话浏览页

**输入**：UI设计稿 + API接口契约 + PRD
**输出**：可运行的前端代码，通过测试智能体验证

---

### A2 - 后端开发智能体

**角色设定**：
- Node.js后端工程师，精通 Express/Fastify
- 擅长文件系统操作、进程管理、流式数据传输

**能力要求**：
- 运行时：Node.js 18+
- 框架：Express 或 Fastify
- 语言：TypeScript
- 文件操作：读写 `~/.pi/agent/` 下的 JSON 配置
- 进程管理：spawn子进程、stdin/stdout管道
- 流式传输：SSE / WebSocket 服务端
- HTTP客户端：axios / node-fetch（用于镜像拉取）

**具体任务**：
1. REST API 服务搭建
2. 配置读写模块（auth.json / models.json / settings.json）
3. 镜像拉取模块（源码 + 依赖 + 模型三层拉取，进度上报）
4. PI对话驱动模块（根据A3的验证结果实现）
5. 会话管理模块
6. 一键安装脚本执行模块

**输入**：API接口契约 + PI驱动机制验证报告
**输出**：可运行的后端服务代码

---

### A3 - PI引擎对接智能体

**角色设定**：
- 源码研究专家，擅长阅读大型开源项目代码
- 熟悉 Agent 运行时、LLM API 调用链

**能力要求**：
- 能读懂 TypeScript/Rust 混合工程
- 理解 Agent 运行时传输抽象（transport abstraction）
- 熟悉 OpenAI 兼容 API 协议
- 能编写 Adapter 层屏蔽引擎差异

**具体任务**：
1. **M0 技术验证**（最关键）：
   - 读 `pi-coding-agent` 源码，确认是否有 server/headless 模式
   - 读 `pi-web-ui` 源码，确认官方网页驱动方案
   - 读 `pi-agent-core` 的传输抽象，确认扩展可行性
   - 输出《PI网页驱动机制验证报告》
2. 编写 `pi-adapter` 适配层
3. 定义统一内部消息模型（为多引擎预留）
4. 编写引擎对接文档，供后续接入 openclaw/Hermes 参考

**输入**：`D:\program\pi-agent\source` 源码访问权限
**输出**：验证报告 + Adapter层代码 + 对接文档

---

### A4 - UI/UX设计智能体

**角色设定**：
- UI/UX设计师，擅长面向小白用户的友好设计
- 理解"零门槛"设计理念

**能力要求**：
- 设计工具：Figma / 直接输出 CSS/Tailwind
- 设计系统：配色、字体、间距、组件库
- 交互设计：引导流程、tooltip、进度反馈
- 主题系统：浅色/深色模式

**具体任务**：
1. 整体视觉风格定义（清新、友好、非技术感）
2. 各页面线框图 / 高保真设计
3. 组件设计规范（按钮、输入框、卡片、tooltip）
4. 引导教程的图文排版设计
5. 主题色板（浅色 + 深色）
6. 图标选择 / 设计

**输入**：PRD + 用户画像（非程序员小白）
**输出**：设计规范 + 页面设计稿（或可直接用的CSS/组件代码）

---

### A5 - 测试智能体

**角色设定**：
- QA工程师，擅长从用户视角发现问题
- 特别关注"小白用户"场景

**能力要求**：
- 单元测试：Jest / Vitest
- E2E测试：Playwright / Cypress
- API测试：Supertest
- 能编写"小白用户场景"测试用例

**具体任务**：
1. 后端API单元测试
2. 前端组件单元测试
3. 端到端流程测试（选项目→拉取→配置→对话 全流程）
4. 异常场景测试（网络断开、Key错误、镜像失败等）
5. 跨浏览器兼容性测试

**输入**：各模块代码 + 测试用例需求
**输出**：测试代码 + 测试报告

---

### A6 - 文档智能体

**角色设定**：
- 技术文档工程师，擅长面向新手的教程写作
- 文笔清晰、步骤详细、配图说明

**能力要求**：
- Markdown 写作
- 技术教程编写（面向非程序员）
- API文档生成（TypeDoc / Swagger）
- 多语言文档（中文为主，英文辅助）

**具体任务**：
1. README.md（项目介绍、快速开始、截图）
2. 部署指南（Windows/macOS/Linux）
3. 模型API申请教程（DeepSeek / 智谱 / 通义 / 豆包）
4. API接口文档
5. 贡献指南（CONTRIBUTING.md）
6. 常见问题（FAQ.md）

**输入**：项目代码 + PRD + 技术验证报告
**输出**：Markdown文档

---

### A7 - DevOps智能体

**角色设定**：
- 运维/发布工程师，擅长GitHub工作流和自动化
- 关注开源项目发布规范

**能力要求**：
- GitHub Actions CI/CD
- npm 包发布
- Git 分支管理策略
- Release 发布流程
- LICENSE 选择

**具体任务**：
1. GitHub仓库初始化配置
2. CI/CD 流水线（自动测试 + 自动构建 + 自动发布）
3. 分支策略（main / develop / feature-*）
4. Release 版本管理
5. 一键安装脚本（Windows PowerShell / macOS bash）
6. GitHub Pages 部署（项目官网）

**输入**：项目代码 + 发布需求
**输出**：CI/CD配置 + 脚本 + 发布文档

