## 1. PI

- **源码位置**：`D:\program\pi-agent\`
- **语言/框架**：TypeScript / Node.js
- **包管理**：pnpm workspace
- **启动方式**：CLI + HTTP API

| 维度 | 详情 |
|------|------|
| **启动命令** | `pnpm start`（后端）、`pnpm dev`（开发模式） |
| **SDK/API** | HTTP REST API + CLI 模式 + SDK 调用 |
| **API 端口**：`http://localhost:1001` |
| **核心包** | `source/packages/agent`（agent 核心）、`source/packages/ai`（模型提供商）、`source/packages/coding-agent`（编码代理） |
| **配置方式** | 环境变量 `PI_CODING_AGENT_DIR`、配置文件 `pi-config.json` |
| **数据目录** | `ai-agent/pi/data/sessions/`、`prompts/`、`skills/`、`config/` |
| **会话格式** | PI 原生 jsonl，含 `session`/`message`/`session_info` 事件，`version:3` |
| **能力** | 流式输出✅ / 思考✅ / 工具调用✅ / 脚本执行✅ / 上下文 128K+ |
| **接入难点** | 已有完整实现，作为 Adapter 基准 |

## 2. Hermes

- **源码位置**：`D:\program\hermes-agent\`
- **语言/框架**：Python / FastAPI
- **包管理**：uv（`.venv/` 虚拟环境）
- **启动方式**：CLI + HTTP 服务 + Web UI

| 维度 | 详情 |
|------|------|
| **启动命令** | `hermes` CLI、`python -m acp_adapter`（ACP 服务）、`uvicorn`（Web 服务） |
| **SDK/API** | FastAPI HTTP 服务 + ACP 协议适配器 + CLI |
| **配置方式** | `hermes_cli/config.py`、环境变量、`cli-config.yaml` |
| **数据目录** | 待确认（默认 `~/.hermes/`），可能支持环境变量重定向 |
| **目录结构** | `agent/`（核心逻辑）、`gateway/`（多平台消息网关）、`acp_adapter/`（协议适配）、`web/`（Web UI）、`tools/`（工具集） |
| **特殊功能** | 多平台网关（Slack/飞书/企业微信/Discord）、MOA（多智能体编排）、TTS 语音 |
| **依赖安装** | `uv pip install -e .` 或 `pip install -e .` |
| **能力** | 流式输出✅ / 思考✅ / 工具调用✅ / 脚本执行✅ / 上下文 128K |
| **接入难点** | Python 环境依赖、ACP 协议对接、FastAPI 服务端口冲突 |

## 3. Claude Code

- **源码位置**：`D:\program\claude-code\`
- **语言/框架**：TypeScript / Node.js（插件生态）
- **性质**：**非独立引擎**，为 Claude Code IDE 的插件/扩展仓库
- **接入方式**：通过 Claude Code 官方 API/SDK 接入

| 维度 | 详情 |
|------|------|
| **启动命令** | 无独立启动，作为 Claude Code 的 plugin/hook 运行 |
| **SDK/API** | Agent SDK（`plugins/agent-sdk-dev/`）、Hooks 系统 |
| **配置方式** | 插件配置 `plugin.json`、环境变量 |
| **核心能力** | Hooks（会话开始/工具使用/停止等）、Agent 定义、命令定义 |
| **可复用** | Agent SDK 示例（`examples/sdk/`）可作为集成参考 |
| **依赖安装** | `npm install` |
| **能力** | 取决于 Claude Code 本身：流式✅ / 思考✅ / 工具✅ / 上下文 200K |
| **接入难点** | 非开源引擎，依赖 Claude Code 官方产品；需通过官方 API 对接 |

## 统一接入建议

### 1. Adapter 接口设计

```typescript
interface EngineAdapter {
  id: string;
  name: string;
  capabilities: EngineCapabilities;
  
  // 启动/停止
  start(config: EngineConfig): Promise<void>;
  stop(): Promise<void>;
  
  // 对话
  sendMessage(sessionId: string, messages: Message[]): AsyncIterable<ChatEvent>;
  
  // 会话管理
  listSessions(): Promise<SessionMeta[]>;
  loadSession(id: string): Promise<Session>;
  deleteSession(id: string): Promise<void>;
  
  // 引擎状态
  getStatus(): Promise<EngineStatus>;
}

interface EngineCapabilities {
  streaming: boolean;
  thinking: boolean;
  toolCalls: boolean;
  scriptExec: boolean;
  contextLimit: number;
}
```

### 2. 接入优先级

1. **PI**（已实现，作为基准）
2. **Hermes**（Python 生态，FastAPI 服务，适合作为第二个验证引擎）
3. **OpenCode**（TypeScript/Bun，HTTP 服务完善，SDK 友好）
4. **Reasonix**（Go + HTTP，npm 包可用）
5. **OpenClaw**（TypeScript，模块庞大但分层清晰）
6. **Codex**（Rust 编译门槛高，SDK 完善可后期接入）
7. **Claude Code**（非开源，通过官方 API 对接）

### 3. 通用接入流程

```
① 拉取引擎源码到 ai-agent/<engine>/program/
② 安装依赖（按引擎要求：pnpm/pip/cargo/go mod）
③ 配置引擎数据目录（环境变量或配置文件）
④ 启动引擎服务
⑤ 通过 Adapter 对接 HTTP API
⑥ 验证对话功能
```
