## 一、选择模型提供商

### 操作方式

```
① 在"选择供应商"列表中点选 → ② 选模型 → ③ 填 Key → ④ 验证 → ✅ 搞定
                                                         ↑
                                                  URL 自动填好
                                                  注册链接一键直达
```

## 二、DeepSeek 设置教程（推荐）

### 整体流程

```
① 注册 DeepSeek 账号  →  ② 创建 API Key  →  ③ 复制 Key 粘贴到 GreenHorn
```

### 第一步：注册 DeepSeek 账号

1. 打开 DeepSeek 官网：**[https://platform.deepseek.com](https://platform.deepseek.com)**
2. 点击右上角的 **"Sign Up"（注册）**
3. 用邮箱注册（推荐）或用手机号
4. 查收验证邮件，点击验证链接
5. 登录你的 DeepSeek 账号

### 第二步：创建 API Key

1. 登录后，在左侧菜单找到 **"API Keys"**
2. 点击 **"Create new key"（创建新密钥）**
3. 给你的 Key 起个名字，比如 `greenhorn`
4. 点击创建
5. ⚠️ **立即复制 Key！** 关闭页面后就看不到了

    ```
    sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    ```

### 第三步：填入 GreenHorn

1. 回到 GreenHorn 的模型设置页面
2. 在 **"API Key"** 输入框中粘贴刚才复制的 Key
3. **"API 地址"** 已自动填好：`https://api.deepseek.com`
4. 点击 **"验证连接"**
5. 看到 ✅ **连接成功** 就完成了！

### 第四步：充值（可选但推荐）

DeepSeek 是新账户需要充值才能调用 API：

1. 在 DeepSeek 平台左侧菜单找到 **"Top Up"（充值）**
2. 首次最低充值 10 元左右
3. 支持支付宝 / 微信支付
4. 10 元可以用很久（普通对话几千次没问题）

## 三、Ollama 本地模型设置（免费方案）

如果不想注册任何账号、不想花钱，可以用本地的 Ollama 运行开源模型。

### 整体流程

```
① 下载安装 Ollama  →  ② 下载模型  →  ③ 配置 GreenHorn
```

### 第一步：下载安装 Ollama

1. 打开 Ollama 官网：**[https://ollama.com](https://ollama.com)**
2. 点击 **"Download"**
3. 选择你的操作系统（Windows / macOS / Linux）
4. 下载完成后，双击安装（一路默认即可）

### 第二步：下载模型

安装完成后，打开终端（Windows 按 `Win+R`，输入 `cmd`，回车）：

```bash
# 下载推荐模型（约 5GB，第一次下载需要等一会儿）
ollama pull qwen3.5:9b

# 查看已下载的模型列表
ollama list
```

下载进度会在终端中显示。

### 第三步：配置 GreenHorn

1. 打开 GreenHorn 的设置页面
2. 在模型提供商中选择 **"Ollama"**
3. API 地址填：`http://localhost:11434`
4. 模型名填：`qwen3.5:9b`
5. 点击 **"验证连接"**
6. 看到 ✅ **连接成功** 就完成了！

> **注意**：Ollama 全部在本地运行，依赖电脑的 CPU 和内存。建议至少 16GB 内存。

## 四、连接验证

无论使用哪个提供商，填写完成后都需要验证连接是否畅通。

### 验证成功

```
✅ 连接成功！
   模型：DeepSeek Chat
   延迟：320ms
   状态：就绪，可以开始对话了！
```

### 验证失败

```
❌ 连接失败
   可能原因：
   · API Key 填错了 → 回到平台重新复制粘贴
   · 网络连接异常 → 检查是否可以访问互联网
   · 服务临时不可用 → 等待几分钟后重试
```

## 五、常见设置问题

| 问题 | 解决方案 |
|------|---------|
| "API Key 格式不对" | 检查是否复制完整（以 `sk-` 开头） |
| "连接超时" | 检查网络，确认是否能访问 DeepSeek 官网 |
| "余额不足" | 登录 DeepSeek 平台 → 充值 |
| "Ollama 连接不上" | 确认 Ollama 已启动并运行在 11434 端口 |
| "不知道选哪个模型" | DeepSeek 新手最友好，推荐先试 |
