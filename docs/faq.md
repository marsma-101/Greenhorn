## 一、安装与启动

### Q：GreenHorn 是什么？需要安装什么？

A：GreenHorn 是一个开箱即用的 AI 智能体工具。你只需要：
1. 你的电脑（Windows / macOS / Linux）
2. 浏览器（Chrome / Edge 等）
3. 跟着部署指南走 5 步，就能开始用

### Q：一定要安装 Node.js 吗？

A：是的。GreenHorn 基于 Node.js 运行。启动器会自动检测并引导你安装，不需要你手动配置。

### Q：启动后终端窗口能关吗？

A：**不能关**。关掉终端窗口 GreenHorn 服务也就停了。想关闭 GreenHorn 时再关即可。

### Q："localhost:3020" 打不开怎么办？

A：试试以下操作：
- 确认启动脚本运行正常（终端里没有报错）
- 确认浏览器地址栏输入的是 `http://localhost:3020`（不要输成 `https://`）
- 尝试换一个浏览器（推荐 Chrome 或 Edge）
- 如果 3020 端口被占用，启动器会自动提示

### Q：可以从另一台电脑访问吗？

A：目前只支持本机访问。后续版本会考虑局域网访问。

## 二、模型与 API Key

### Q：什么是 API Key？一定要吗？

A：API Key 是你的"通行证"，AI 模型提供商用它来识别你是谁。DeepSeek 等云端模型需要 API Key。如果你不想申请，也可以用本地模型（Ollama），完全免费。

### Q：DeepSeek 的 API Key 怎么申请？

A：请看 **[模型 API 设置指南](model-setup.md)**，里面有完整的分步图文教程。

### Q：API Key 安全吗？会不会泄露？

A：你的 API Key **仅保存在你本机**，GreenHorn 不会上传到任何云端。放心使用。

### Q：用 DeepSeek 要花多少钱？

A：非常便宜。首次充 10 元，普通对话几千次都用不完。详细价格可查看 DeepSeek 官网定价。

### Q：能用其他模型吗？比如通义千问、智谱？

A：目前 MVP 支持 DeepSeek 和本地 Ollama。更多模型支持在后续版本中加入。

### Q：不想用云端模型，想完全本地跑可以吗？

A：可以。安装 Ollama + 下载一个本地模型（如 qwen3.5:9b），然后在 GreenHorn 配置中选 Ollama，全程不用联网。

## 三、对话与使用

### Q：GreenHorn 能做什么？

A：GreenHorn 是一个 AI 智能体"外壳"。装上不同的"引擎"就能做不同的事：
- **PI 引擎**：写代码、读代码、调试代码、写文档等
- 未来还会支持更多引擎

### Q：对话输入后没有回复怎么办？

A：按顺序检查：
1. ✅ **API Key 填对了吗？** → 在设置页面重新验证
2. ✅ **网络通吗？** → 试试打开 DeepSeek 官网
3. ✅ **余额够吗？** → 登录 DeepSeek 查看余额
4. ✅ **终端在运行吗？** → 确认启动脚本没有被关闭

### Q：对话一半卡住了怎么办？

A：点击对话输入框旁边的 **"停止"** 按钮，然后重新输入。

### Q：可以撤销/编辑已发送的消息吗？

A：当前版本不支持。可以先复制你想修改的内容，重新发送。

### Q：怎么看历史对话？

A：在对话工作台左侧或顶部的菜单中，找到 **"历史会话"** 入口，可以查看和恢复之前的对话。

## 四、配置与设置

### Q：参数（温度、上下文长度）是什么意思？

A：所有参数旁边都有 **问号(?)** 帮助提示，把鼠标放上去就会看到大白话说明。一般保持默认值就可以。

### Q：怎么切���浅色/深色主题？

A：在设置面板找到 **"主题"** 选项，选浅色或深色。

### Q：界面上的问号圆圈有点烦，能去掉吗？

A：当然可以。在设置面板找到 **"显示帮助说明"** 开关，关掉它之后所有问号圆圈就消失了。

## 五、故障排除

### Q：安装时卡在"正在安装依赖"很久不动？

| 可能原因 | 怎么做 |
|---------|--------|
| 网络慢 | 耐心等待 1-2 分钟 |
| 镜像源不可用 | 切换国内镜像源（系统提示里会有选项） |
| 防火墙拦截 | 暂时关闭防火墙重试 |

### Q：启动时提示"端口被占用"？

A：这是正常的，说明 3020 端口被其他程序占用了。启动器会自动找一个空闲端口。如果没自动处理，可以手动指定端口。

### Q：卸载 GreenHorn 怎么操作？

A：删除 GreenHorn 文件夹即可。所有配置和会话数据也都在该文件夹内，一并删除。

### Q：更新怎么办？

A：目前需要重新下载最新版本覆盖安装。自动更新功能在规划中。
